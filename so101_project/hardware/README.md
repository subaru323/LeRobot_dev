# hardware（刷る部品と、その作り方）

- 役目：このプロジェクトで新しく設計して刷る部品（STL）と、それを書き出す道具。
- 出どころ：[進め方_利用者の稼働を絞る](../docs/plan/進め方_利用者の稼働を絞る.md) の W2・W6（2026-11-18）。持ち主は docs を書く会話（`sim/` の持ち主とは別）。
- 作り方（2026-11-26 の利用者の決定「Claude がコードで」：刷る物は Claude がコードで STL を出す。Fusion は使わない。寸法の元はコードの側に置き、Fusion では開いて見るだけ）：
  - 箱だけの片：`python hardware\make_stl.py`（numpy だけ）
  - 穴や曲がった縁のある部品：システムの `python`（CadQuery 2.8・shapely が入っている。LeRobot の `.venv` には無い）。例 `python hardware\make_base_clamp.py`。`--selftest` で検算する。CadQuery はこのパソコンでは python の終わりの後片付けで落ちる（0xC0000374）ので、道具は出し終えた後に `os._exit` で抜ける。

## 押さえ（予備）（2026-11-26）

土台の 4 つの皿穴が使えないとき（穴が潰れている、ねじが入らない）のための物。点検 C71 で、じかに留めるほうが良いと分かったので、使わない。

- 形：土台の形は本家の土台の STL（`sim/models/src/assets/base_so101_v2.stl`）を高さ 10mm で切って取る。羽根の縁から 0.4mm 離れて立つ壁（厚さ 5mm）、羽根の上に 6mm かぶさる爪（厚さ 4mm）、外の足（幅 14mm・厚さ 5mm）に皿の穴 1 つ。高さは合板から 21.5mm。
- `--selftest` で確かめていること：土台の底が 0・羽根の上の面が 17.5mm、腕の座標で土台の後ろの縁が −22.4、どの押さえも土台に食い込まない、ねじの先が合板の裏に抜けない。負の検算（壁を羽根に 1mm 食い込ませると見つける）。
- **使う前に直すこと（点検 C71）**：
  - すき間 0.4mm と 1 個 1 本のねじでは、土台が 1° ほど回れ、肩から 250mm で 4mm ほどずれる（点検役が輪郭を動かして出した値）。すき間を詰める・板ばねにする・ねじを 2 本にする。
  - 爪の下の面は、支えの無い張り出し（壁から 6.4mm）で、その面が羽根に当たる面になる。「支えは要らない」は誤り。支えを付けるか横に寝かせて刷る。爪の高さは刷った壁の高さで決まり、ねじでは変わらない（`LIP_GAP` の説明は誤り）。
  - 腕との当たり：点検役が URDF の関節の範囲を粗い格子で振ると、机に当たらない 50,531 の姿勢のうち 494 が押さえの箱（高さ 21.5mm まで）に入った。校正で関節を手で端まで回すときも当たりうる。
  - `out/base_clamp.json` は腕（URDF）の向き（y が腕の左）。`sim/` の画面の向きは (x, z, −y)、型紙 `make_template.py` は +z が腕の右なので、渡すときに左右を入れ替える。
  - 自己検査の弱み：座標の写し方の検査が写し方と同じ式で、向きの誤りを見つけない。食い込みは土台の STL だけと比べ、モーターの台・回る肩の部品とは比べない。爪の広さには丸みと穴の上が入る（平らな面に当たるのは 61.5・70.4mm² ほど）。
