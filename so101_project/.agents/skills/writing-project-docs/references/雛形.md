# 雛形

## CLAUDE.md

```markdown
# <プロジェクトの名前>

最初に `STATUS.md` を読む（目的・現在地・次の一手）。

## コマンド

- テスト: `<コマンド>`（1つだけなら `<コマンド>`）
- ビルド・確かめ: `<コマンド>`

## 誤解しやすい所

- `<生成されるファイル>` は手で直さない。`<元のファイル>` を直して `<コマンド>`。
- <使っていないように見えて使っている所、真似してはいけない古い書き方>
- <リポジトリの外で決まったこと（デプロイ、利用者との約束）>
```

2回直したことは「誤解しやすい所」に足す。200 行を超えそうなら、たまに要るものをスキルか別の文書に移す。

## STATUS.md

```markdown
# 現在地

## 目的
<1〜3行。利用者の言葉があれば日付つきで引く>

## 決まったこと
- <日付> <決まったこと>（理由）

## 現在地
- <どこまでできたか。確かめた方法>

## 次の一手
1. <AI だけでできること>

## 利用者の判断待ち
- <決めてほしいこと。選択肢と勧め>
```

## 依頼書

```markdown
## 何をしてほしいか
<対象のファイル>で<起きていること>。<終わった>と言えるのは<決め方>のとき。

## 確かめ方
`<コマンド>` が通ること。

## すでに分かっていること・やらないこと
- <会話で決めたこと、試して駄目だったこと>
- <触らない範囲>

## 返してほしいもの
- 変えたファイルと要点
- 実行したコマンドとその出力
```
