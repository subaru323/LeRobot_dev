## A. 学習用のパソコン（NVIDIA の GPU を持っている人）

### A-1. 聞くこと

持ち主に次を聞きます。

| 項目 | 答え |
|---|---|
| GPU の型番（例：RTX 4060） | |
| GPU のメモリ（例：8 GB） | |
| OS（Windows / Linux） | |
| Python と uv を入れてよいか | |
| 学習を数時間回してよいか（その間パソコンを使えない） | |
| （Windows なら）「開発者モード」をオンにしてよいか。だめなら、管理者の PowerShell で学習を流してよいか | |

- Windows なら、デスクトップを右クリック →「NVIDIA コントロールパネル」→「システム情報」、または PowerShell で `nvidia-smi` を実行すると、型番とメモリが出ます。
- 開発者モードの理由：Windows では、学習の途中保存で LeRobot が作るシンボリックリンクに、開発者モードか管理者が要る。無いと保存の所で落ちる（[Windows で学習の保存が落ちる](knowledge/Windowsで学習の保存が落ちる.md)）。設定 → システム → 開発者向け → 開発者モード。
- ACT が何 GB のメモリで回るかは確かめていません。足りないときは、学習の「バッチサイズ」を下げて回します（手順書 13-1 の試しで確かめる）。

### A-2. インストール

組み立て手順書の STEP 1（Git、uv、LeRobot）と同じです。**最後に、GPU 版の PyTorch に入れ替えます**（組み立て手順書の手順だけだと、CPU 版になる可能性がある。このパソコンは CPU 版だった）。

1. 組み立て手順書 STEP 1-1〜1-3 を、そのパソコンで行います（`git checkout 53feaef` で、このパソコンと同じ版にそろえる）。
2. 次を実行し、`cuda True` と出るかを確かめます。
   ```powershell
   python -c "import torch; print(torch.__version__, 'cuda', torch.cuda.is_available())"
   ```
3. `cuda False` なら、PyTorch の公式サイト https://pytorch.org/get-started/locally/ で、OS と CUDA の版を選んで出るコマンド（`pip install torch ... --index-url ...`）の頭に `uv ` を付けて実行し、2 をもう一度確かめます。どの CUDA の版を選べばよいかは、`nvidia-smi` の右上の「CUDA Version」以下のものを選びます（未確認。そのパソコンで確かめる）。
4. Hugging Face に、自分のアカウントでログインします（D の後で。手順書 10）。

### C-3. 取り付け（フォロワーの手首）

## D. Hugging Face の組織を作る

データと学習した方策を、チームで 1 か所に置くための場所です。一人ずつのアカウントで入るので、トークンを人と分け合いません。

### D-1. 作る人（1 人。管理者になる）

1. 自分の Hugging Face のアカウントでログインします（無ければ https://huggingface.co/join で作る）。
2. https://huggingface.co/organizations/new を開き、組織の名前を決めて作ります（Hugging Face の案内による）。名前は、データの名前の頭（`<組織名>/cube_pick`）になります。
3. 組織の設定（Organization settings）→「Members」を開き、メンバーを招待します。招待のリンクを作る、一人ずつ足す、メールでまとめて送る、のどれかでできます。
4. メンバーの役割（Role）を **`write`** にします（組織のデータと方策を作って、書き込める）。管理者は `admin` です。
   - `contributor` にすると、自分で作ったものだけを書き換えられます。記録する人と学習する人が違う場合、学習する人が記録のデータを読むことはできますが、書き換えはできません（Hugging Face の案内による）。迷ったら `write` にします。

### D-2. メンバー（全員）

1. 自分のアカウントを作り、招待を受けます。
2. https://huggingface.co/settings/tokens で、**自分の**書き込みのトークンを作ります。
3. 記録するパソコンと学習するパソコンで、手順書 10 の `hf auth login` をします。
4. 手順書の `<HFユーザー名>` には、**組織の名前**を入れます。

- 費用：組織を作ること自体と、非公開のデータを置くことに費用がかかるか、容量の上限がいくつかは確かめていません。作るときに画面の表示を確かめます。

## E. 赤い立方体と箱

### E-1. 選び方の目安

本家の資料に決まった大きさは書かれていません。次は、学習しやすくするための目安です（**未確認**。E-2 で、実物で確かめて決める）。

| 物 | 目安 | 理由 |
|---|---|---|
| 立方体 | 一辺 2.5〜3 cm、軽い（木、発泡材、プラスチック）、つやの無い赤 | グリッパーで余裕を持ってつかめ、落としても壊れない。つやがあると、照明が映り込んでカメラで見えにくい |
| 箱 | 口が 10〜15 cm 四方、高さ 5 cm 前後、立方体と違う色 | 口が広いと入れやすい（最初は易しくする）。高すぎると、腕が箱の縁に当たる |
| 机 | 立方体と違う色の、無地の面 | カメラで立方体を見分けやすい |

- 100 円ショップの木のブロックや、ふた付きの紙箱で十分です。
- 立方体は、予備を含めて 2〜3 個あると、記録の片付けが早くなります。

### E-2. 決め方（リーダーができた後、テレオペで）

1. フォロワーの前の机に、立方体を置きます。
2. テレオペ（組み立て手順書 STEP 8）で、立方体をつかみ、持ち上げ、箱に入れてみます。
3. 次を確かめます。

| 確認項目 | 確認 |
|---|---|
| グリッパーを開いたとき、立方体がらくに入る | [ ] |
| つかんで持ち上げても、滑って落ちない | [ ] |
| 箱の口まで腕が届き、箱の縁に腕が当たらない | [ ] |
| 正面のカメラの映像で、立方体と箱がはっきり見える | [ ] |

4. 通らなければ、大きさや素材を変えます。決まったら、箱の位置を机にテープで固定します（記録の間、箱は動かさない）。
