## STEP 1　Bambu Studioの設定

画面左上に、「プリンター」「フィラメント」「プロセス」の3項目が並んでいます。
（表示が英語の場合に備えて、英語名を（ ）で添えています）

### 1-1. プリンター（Printer）

| 項目 | 設定 |
|---|---|
| プリンター | Bambu Lab A1 mini 0.4 nozzle |
| プレートタイプ | 実機と同じもの（A1 miniの標準は Textured PEI Plate） |

### 1-2. フィラメント（Filament）

| 項目 | 設定 |
|---|---|
| プロファイル | Generic PLA High Speed（Ender Fast PLA は高速印刷向けのPLAのため。一覧になければ「フィラメントを選択/追加」から追加） |
| ノズル温度 | 210〜220℃（販売ページの仕様は190〜230℃） |
| ベッド温度 | 55〜60℃（販売ページの仕様は45〜60℃） |

温度を変えたら、フィラメント名の横の保存アイコンで「**SO101用**」という名前で保存します（保存しないと、次に開いたとき元に戻ります）。

### 1-3. プロセス（Process）

1. プリセットで **0.20mm Standard @BBL A1M** を選びます。
2. 右上の「**詳細**」（Advanced）スイッチをオンにします。
3. 次の表のとおり設定します。

| タブ | 項目 | 値 | 備考 |
|---|---|---|---|
| 品質（Quality） | 積層ピッチ（Layer height） | 0.2mm | プリセットで設定済み |
| 品質（Quality） | X-Y穴補正（X-Y hole compensation） | **+0.075mm（仮）** | STEP 2の結果で確定させる。値は穴の片側の量で、穴の幅は2倍の量だけ広がる（公式Wiki：0.5mm小さい穴には +0.25mm） |
| 強度（Strength） | 壁ループ数（Wall loops） | 3 | 壁を厚くして強度を上げるため（README には無い、この手順書の判断） |
| 強度（Strength） | 充填密度（Sparse infill density） | 15% | README の推奨値 |
| サポート（Support） | サポートを有効化（Enable support） | オン | |
| サポート（Support） | タイプ（Type） | 標準（自動） / normal(auto) | |
| サポート（Support） | しきい値角度（Threshold angle） | 45° | README「水平から45°より急な斜面にはサポート不要」に合わせる。初期値は30° |

4. プリセット名の横にある保存アイコンを押して、「**SO101用**」という名前で保存します。

## STEP 2　ゲージの試し刷り（穴の寸法合わせ）

### 2-1. 目的

本番の部品には、STS3215モーターをはめる穴があります。この穴が、きつすぎずゆるすぎない大きさに仕上がるよう、先に小さなゲージで確認します。

### 2-2. ゲージの種類

| ファイル | 寸法 | 役割 |
|---|---|---|
| `Gauge_0.STL` | 本番の部品と同じ | **判定に使う** |
| `Gauge_tight_1.STL` | 0より0.1mm狭い（STLで測った穴：Gauge_0 が 34.9×24.7mm、tight が 34.8×24.6mm） | 比較用。プリンターのずれがどちらの方向かを見る（もう刷らなくてよい） |

### 2-3. これまでの記録

| 回 | 刷ったもの | X-Y穴補正 | 結果 | 判断 |
|---|---|---|---|---|
| 1回目 | Gauge_0 | 0 | きつすぎるが入る | 穴が小さめに出来る |
| 1回目 | Gauge_tight_1 | 0 | 入らない | 同上 |
| 2回目 | Gauge_0 | +0.075mm | （記入） | （記入） |

### 2-4. 2回目の試し刷り手順

1. プレートに `Gauge_0.STL` を1個だけ置きます。**向きは変えません。**
2. プロセス設定が「SO101用」（X-Y穴補正 +0.075mm）になっていることを確認します。
3. スライスしてプリントします。
4. STS3215モーターをはめて、お手本動画（ https://youtu.be/dss8E3DG2rA ）と比べます。
5. **モーターを力ずくで押し込まないこと。** ゲージが割れたり、モーターに傷が付いたりします。

### 2-5. 判定

| 結果 | 対応 |
|---|---|
合格の目安は、**お手本動画と同じくらいのはまり具合**です（README は「動画と同じくらい」とだけ書いています）。

| 結果 | 対応 |
|---|---|
| お手本動画と同じくらい（手で押すと入り、ガタつかない） | **合格**。この値で確定し、STEP 3へ |
| まだ少しきつい | +0.10mmに変えて、ゲージをもう1個刷る |
| ガタつく | +0.05mmに変えて、ゲージをもう1個刷る |
| 1回目とはまり具合がまったく変わらない | 設定が反映されていない可能性が高い（ゲージの穴は閉じた穴なので、X-Y穴補正が効くはず）。プロセスが「SO101用」になっているか、値が入っているかを確かめて、もう1個刷る |

値を変えたら、「SO101用」プリセットに**上書き保存**し、2-3 の表に1行足して記録します。ゲージは小さいので、刷り直しの手間はわずかです。

ノギスがあれば、刷ったゲージの穴の幅を測って記録すると、次に値を決めるときの手がかりになります（設計値は 34.9×24.7mm）。

### 2-6. 確定値

| 項目 | 確定した値 |
|---|---|
| X-Y穴補正 | 0.15 mm |
| X-Y輪郭補正（使った場合） | 不使用 mm |

- [☑] STEP 2 完了

## STEP 3　本番データの準備

### 3-1. プレートごとに読み込んで、使わない部品を消す

まとめファイルの部品は、A1 mini のプレート（18cm角）1枚ずつに収まる3つのかたまりに並んでいます（STLで測って確かめました）。かたまりをドラッグで移すと並びが崩れやすいので、**プレートごとにまとめファイルを読み込み、そのプレートで使わない部品を消す**やり方にします。

| プレート | 残す部品（公式ファイルの並び） | かたまりの大きさ（STLで測った値） | 使うプリンター |
|---|---|---|---|
| プレート1 | Base、Rotation_Pitch、Wrist_Roll_Pitch、Motor_holder_Base、Motor_holder_Wrist | 170×147mm | 1号機 |
| プレート2 | Upper_arm、Under_arm | 144×141mm | 2号機 |
| プレート3 | Handle、Wrist_Roll、Base_motor_holder、Trigger、取り付け板 | 146×152mm | 先に空いたほう |

1. Bambu Studioで新しいプロジェクトを作り、プロセスとフィラメントに「SO101用」を選びます。
2. プレートを追加して3枚にし、プレート1を選びます。
3. `BambuLabA1mini_Leader_SO101.stl` をプレートにドラッグします。全体は約38cm角で、プレートからはみ出しますが問題ありません。
   - **「縮小しますか」と聞かれたら「いいえ」**を選びます。縮小すると、モーターが入らなくなります。
   - 読み込んだら、右側の拡大率（Scale）が **100%** のままか確かめます。
4. モデルを右クリックし、「**分割**」→「**オブジェクトに分割**」（Split → To objects）を選びます。
5. 上の表の「残す部品」以外を、選んで Delete キーで消します。**部品の向きは変えないでください。** 最初からプリントしやすい向きになっています。
6. 残った部品をまとめて選び、プレートの真ん中へ移します。プレート1は余白が片側5mmほどしかありません。プレートの枠からはみ出すと、Bambu Studio が警告を出すので、出なくなるまで位置を直します。
   - どうしても収まらないときは、そのプレートで「配置」（Arrange）を押すと、自動で並べ直します。
7. プレート2、プレート3でも、2〜6を同じように行います。
8. ここで一度、プロジェクトを保存します。

部品ごとのファイル（ https://github.com/TheRobotStudio/SO-ARM100/tree/main/STL/SO101/Individual ）は、向きが印刷用になっていないものがあります（Handle、Wrist_Roll など）。使うのは、Seeed製の基板用の取り付け板を差し替えるときだけにします。

### 3-2. 部品が12個そろっているか確認

分割した部品には、番号だけの名前が付くことがあります。下の大きさ（一番長い辺。STLで測った値）で見分けてください。

| 区分 | 部品名（ファイル名） | 一番長い辺 | 確認 |
|---|---|---|---|
| 共通 | Base_SO101 | 111mm | [ ] |
| 共通 | Base_motor_holder_SO101 | 80mm | [ ] |
| 共通 | Motor_holder_SO101_Base | 55mm | [ ] |
| 共通 | Motor_holder_SO101_Wrist | 56mm | [ ] |
| 共通 | Upper_arm_SO101 | 142mm | [ ] |
| 共通 | Under_arm_SO101 | 131mm | [ ] |
| 共通 | Rotation_Pitch_SO101 | 84mm | [ ] |
| 共通 | Wrist_Roll_Pitch_SO101 | 78mm | [ ] |
| 共通 | WaveShare_Mounting_Plate_SO101（Seeed製の基板なら差し替え） | 51mm | [ ] |
| リーダー専用 | Handle_SO101 | 88mm | [ ] |
| リーダー専用 | Trigger_SO101 | 65mm | [ ] |
| リーダー専用 | Wrist_Roll_SO101 | 67mm | [ ] |

分割すると、細かい破片が余分にできることがあります。12個より多い場合は、部品の一部でないことを確認してから削除してください。

### 3-3. 本番の前に、実部品1個で確かめる

**ゲージで合格しても、本番の部品がきついことがあります。** X-Y穴補正が効くのは、各層で閉じた穴だけです（Bambu Lab 公式Wiki）。ゲージのモーター穴は閉じた穴ですが、本番の部品は、モーターがはまる面の多くが閉じた穴にならない向きで刷られます（STLの断面で調べた結果。モーターの大きさの閉じた穴が現れたのは Wrist_Roll_Pitch だけでした）。

1. プレート1の **Motor_holder_SO101_Base** を右クリックして複製し、空いているプレートに1個だけ置いて刷ります（小さいので早く終わります）。
2. STS3215モーターにかぶせてみます（組み立て手順書 STEP 4 の関節1で、モーターにかぶせる部品です）。

| 結果 | 対応 |
|---|---|
| 無理なくかぶさる | そのまま STEP 4 へ。刷った部品はそのまま使えるので、プレート1の Motor_holder_Base は消してかまいません |
| きつい | 「X-Y輪郭補正」（X-Y contour compensation）を -0.05mm にして、もう1個刷る。輪郭補正は、閉じていない穴の幅を広げますが、**部品の外形も細くなります**（ほかの部品とはまる所やネジの周りの厚みも変わる）。値を変えたら、STEP 2-6 の表に記入し、プリセットに上書き保存します |

## STEP 5　プリント

### 5-1. プリンターに送る

**方法A：Wi-Fiで送る**
1. 右上の「**プリント**」（Print plate）を押します。
2. 送信先のA1 miniを選びます。プレート1は1号機、プレート2は2号機、プレート3は先に終わったほうです。
3. 「ベッドレベリング」はオンのまま、「送信」を押します。

**方法B：microSDで渡す**
1. 「プリント」ボタン横の ▼ →「**エクスポート**」（Export plate sliced file）を選びます。
2. `.gcode.3mf` ファイルをmicroSDに保存します。
3. A1 miniにmicroSDを挿し、本体の画面でファイルを選んで開始します。

### 5-2. プリント中の注意

- **1層目がきれいにプレートへ貼り付くまで見届けます。** 剥がれなどの失敗は、1層目で起きることが多いためです（経験則）。
- 時間に余裕があれば、プレート1（モーターがはまる部品が多い）を先に刷り、終わったら組み立て担当とモーターをはめて確かめてから、プレート2・3を始めます。合わなかったときの刷り直しが1枚分で済みます。
- 途中で、部品がプレートから剥がれていないか、ときどき様子を見ます。

### 5-3. よくある失敗と対処

| 症状 | 対処 |
|---|---|
| 1層目がプレートに付かない | プレートを洗い直す。指で触った跡（皮脂）が原因のことが多い |
| 途中で部品が剥がれた | その部品だけを新しいプレートに移して、刷り直す |
| 細い糸を引いたような線が多い | 見た目だけの問題なので、後でカッターで取る。多すぎる場合はフィラメントが湿気を吸っている可能性がある |

| プレート | 開始日時 | 終了日時 | 結果 |

| プレート2（2号機） | | | |

## STEP 6　後処理と検品

### 6-1. 取り外し

1. プレートが**冷めてから**外します。
2. プレートを軽く曲げると、部品が剥がれます。

### 6-2. サポート除去

1. 小さなマイナスドライバーを、サポートの下に差し込んで剥がします。
2. **Triggerは細くて折れやすい**ので、力を入れすぎないようにします。
3. ネジ穴とモーターを入れる穴の中に、サポートやバリ（はみ出したカス）が残っていないか確認します。

### 6-3. 検品

| 確認項目 | 確認 |
|---|---|
| 12個すべてそろっている（STEP 3-2の表で再確認） | [ ] |
| ネジ穴にサポートやバリが残っていない | [ ] |
| モーターを入れる穴に、STS3215が入る | [ ] |
| 割れや、層の剥がれがない | [ ] |
| 反り（平らな面が浮いている）がない | [ ] |

不良があった部品は、その部品だけを刷り直します。

## 保管とメモ

- 使わないフィラメントは、乾燥剤と一緒に袋に入れて保管します。湿気を吸うと、糸引きや割れの原因になります。
- 「SO101用」プリセットは、フォロワー部品を刷り直すときにも使えます。フォロワー用の A1 mini 向けまとめファイルは `STL/SO101/Follower/BambuLabA1mini_Follower_SO101.stl` です。
