# 道具の使い方

core の道具は `docs/core/tools/` にある。どれもプロジェクトのルートで実行する。python 3 と Claude Code の CLI（`claude`）が要る。python の無いプロジェクトでは、道具の手順を目で行う（下の「道具が使えないとき」）。

## 結果の文書の検査: `python docs/core/tools/doc_lint.py <文書> [<文書> ...]`

- 拾うもの: (1) 使ってはいけない言葉（「効かない」「ほぼ効かない」「差は無い」「差が無かった」など。「」で囲んだ言及や、直後が「とは言えない」などの打ち消しなら数えない）。(2) 手で書いた割合・倍率の疑い（「約2割」「43%」「1.5倍」など。同じ行に出典の印（「集計」「出力」「表の」）があれば数えない）。
- 何も見つからなければ「見つからなかった」と出し、終了コード 0。見つかれば行ごとに出し、終了コード 1（失敗ではない）。
- 限界: 引用（`>` で始まる行）、表、コードの行は検査しない（表の数字は目で見る）。割合は、正しく計算した値も疑いとして拾う（空振りが多い。最後は目で見る）。禁止語の表に無い言い替えは拾えない。

## 結論の点検（R-001）: `python docs/core/tools/r001_check.py`

`rules/RULES.md` の R-001 を見る。点検役は `--safe-mode` で起動するので、プロジェクトの CLAUDE.md と自動メモリは入らない（2026-10-14 に確かめた）。`--allow-read` を付けないときは、プロジェクトの外の一時フォルダで起動する。点検の入出力は `docs/records/checks/<日付>_<題>/` に置くとよい。

## 道具が使えないとき

- 検査: 結果の文書を書いたら、禁止語と、手で計算した数字が無いかを目で見る。
- 点検: 新しい会話（Claude Code で新しいセッション）を開き、`tools/r001_prompt.md` の `{{...}}` を埋めた文を渡す。自動メモリが入る点に注意し、結果に「メモリあり」と書く。
