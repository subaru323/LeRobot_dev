## 12拍の模擬比較

すべての保留品が棚を1枠ずつ使う。空から始め、4・8・12拍目の各冒頭に、待ちがあれば1個だけ再検査が終わって棚から出る。分散は1・3・5・7・9・11拍、集中は1〜6拍にそれぞれ1個ずつ到着する。最初の再検査が1回休む場合も調べた。

| 保留の発生 | 再検査 | 枠数無制限で最大何個待つか | 2枠の場合に受け入れられない到着数 |
|---|---|---:|---:|
| 分散6個 | 予定どおり | 4 | 2 |
| 集中6個 | 予定どおり | 5 | 3 |
| 分散6個 | 4拍目の完了なし | 5 | 3 |
| 集中6個 | 4拍目の完了なし | 6 | 4 |

予定どおりに再検査できる場合、棚を4枠にすると分散は全件入るが、集中では6拍目の1件が入らないことも確かめた。

2枠のモデルは、満杯の到着を棚に入れず、残りの時系列を同じ条件で流した。数えたのは受け入れられない到着で、実設備の停止回数や停止時間ではない。無制限でも予定どおりの12拍後に3個残る。この負荷が繰り返されるなら、棚を増やすだけでは待ちを解消できない。

## Claude に渡す一件

架空セルの担当に、独立した12拍の試験として渡す。まず同一拍で「完了が空きを作ってから到着」と「到着が先」を両方再生する。次に満杯を実際の待ち信号にして、上流が止まるまでに到着する部品、棚から出せない期間、再検査中の停止をモデルへ入れる。棚の必要枠数、上流の待ち時間、再検査を終えた数、保留品の所在と引き渡し漏れで候補を比較する。CRX・デンソー案件では、同じ試験票で上流停止の応答、再検査所要時間、満杯検知を現地で測る。今回は棚の購入数を決める段階には至っていない。

## 再現コード

~~~python
def replay(arrivals, slots=(4, 8, 12), capacity=None):
    count = peak = blocked = 0
    for tick in range(1, 13):
        if tick in slots and count:
            count -= 1
        if tick in arrivals:
            if count == capacity:
                blocked += 1
            else:
                count += 1
        peak = max(peak, count)
    return peak, blocked, count

for arrivals in ((1, 3, 5, 7, 9, 11), (1, 2, 3, 4, 5, 6)):
    for slots in ((4, 8, 12), (8, 12)):
        print(arrivals, slots, replay(arrivals, slots), replay(arrivals, slots, 2))
for arrivals in ((1, 3, 5, 7, 9, 11), (1, 2, 3, 4, 5, 6)):
    print(arrivals, replay(arrivals, capacity=4))
~~~
