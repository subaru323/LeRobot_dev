# 2026-11-23　排除の撮り直し画像が設備の整定後かを確かめる

設備保守と品質保証向け。前回は箱の目印で「どこに入ったか」を確かめた。今回はその画像が「いつ撮られたか」を扱う。架空セルには古い絵に新しい時刻が付く試験があり、現行モデルではカメラと腕が一つの時計を使う。機種を移す前に、画像の受信・撮像・設備の整定を区別して再生できると、通信遅れと排除失敗を切り分けやすい。[箱の基準](2026-11-22_排除箱の基準を画像で読む.md)・[架空セル](../../industrial/README.md)

## 15条件の模擬比較

真の整定終了を 0 ms、真の露光開始を −4、−1、0、1、4 ms とした。露光は 4 ms、受信は露光の終了から 10 ms 後。カメラ時計のずれは −2、0、2 ms とした。採点は真の開始が整定終了より厳密に後なら適格。候補方式は時計ずれの上限と露光時間から求めた露光開始の下限が、整定終了の上限を超える場合に画像を使う。

| 画像の採用条件 | 適格画像を使用 | 整定前または整定と同時に始まる画像を使用 | 適格画像を保留 | その他の保留 |
|---|---:|---:|---:|---:|
| 受信が整定後 | 6 | 9 | 0 | 0 |
| カメラの露光中央時刻が整定後 | 6 | 4 | 0 | 5 |
| 露光開始の下限が整定終了の上限より後 | 3 | 0 | 3 | 9 |

下限と上限が一致する例、時計の換算誤差の上限が欠ける例も保留になった。条件を厳しくすると使える画像が減るため、次の撮影までの時間も測る。今回の数字は画像の時刻判定のみ。排除の正否、実機の時刻精度や露光方式は未検証。

## Claude に渡す一件

架空セルで「撮像番号・露光区間・受信時刻・整定の根拠」を記録して再生する。再撮影を頼む場合は要求と新規フレームを対応づける。古い画像の時刻を付け直した例、時計が再起動した例、画像内の対象部分だけ露光が整定をまたぐ例を追加する。CRXとデンソーへ移すときは、設備の完了信号が表す状態と、カメラが返す時刻の定義を確認する。整定後の画像を採用できる件数、誤使用、保留、再撮影で増えた時間を同じケースで測る。実機で根拠が揃う条件は機種別の受入表に残す。

## 再現

~~~python
from collections import Counter
from itertools import product

rows = list(product((-4, -1, 0, 1, 4), (-2, 0, 2)))
totals = [Counter() for _ in range(3)]
for start, offset in rows:
    # Settled at 0, exposure lasts 4 ms, receipt is 10 ms after exposure.
    # Camera clock offset is bounded by 2 ms.
    midpoint = start + 2 + offset
    receipt = start + 14
    decisions = (receipt > 0, midpoint > 0, midpoint - 2 - 2 > 0)
    for tally, accept in zip(totals, decisions):
        tally["valid" if start > 0 else "invalid", "use" if accept else "hold"] += 1
for tally in totals:
    print([tally[k] for k in (("valid", "use"), ("invalid", "use"), ("valid", "hold"), ("invalid", "hold"))])

def eligible(midpoint, exposure_ms, offset_bound, settled_upper):
    if offset_bound is None:
        return False
    return midpoint - exposure_ms / 2 - offset_bound > settled_upper

assert not eligible(4, 4, 2, 0)  # Lower bound equals settled upper bound.
assert not eligible(20, 4, None, 0)
assert eligible(5, 4, 2, 0)
~~~
