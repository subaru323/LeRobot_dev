## カメラの付け方

### 上のカメラ（推す：本家の `Overhead_Cam_Mount_32x32_UVC_Module`）

**2026-11-17 に利用者が候補 C（別の柱で真上から）に決めた（決めたこと 7）。この節は、前に推した本家の台の記録。**

置き場所（2026-11-16 に README とファイルの一覧を見た）：
https://github.com/TheRobotStudio/SO-ARM100/tree/main/Optional/Overhead_Cam_Mount_32x32_UVC_Module

- README の狙い：使う人の間で、カメラの位置と腕の間隔をそろえる（データがそろう）。作業場所の全体を上から見る（README の言葉は「overhead view」で、真下を向くとは書いていない）。腕 1 本でも 2 本でも使える。
- 作り：**腕の土台の下に敷く板（Arm Base）** に、カメラの柱（下・中・上の 3 つ）を差し込み、上の部品にカメラを留める。腕は板の上に載せ、いつものクランプで留めると柱も一緒に押さえられる（README）。
- 要る物（README）：

| 物 | 数 | 備考 |
|---|---|---|
| 32 mm × 32 mm のカメラモジュール | 1 | README の推奨は Amazon（米国）の ASIN `B0CLRJZG8D`。手首用の推奨（`B0CNCSFQC1`）とは別の品。日本で買える同じ品と、画角は**まだ調べていない** |
| `arm_base.stl` | 腕 1 本に 1 | 86,884 バイト |
| `cam_mount_bottom.stl` | 1 | 48,684 バイト |
| `cam_mount_middle.stl` | 1 | 56,984 バイト |
| `cam_mount_top.stl` | 1 | 69,684 バイト |
| M2 のネジ | 16 | モーターに付いてきた小さいネジ |

- 映像の設定（README）：30 fps、640 × 480（作業場所が広ければ 1280 × 720）。
- 気を付けること：
  - 板を腕の下に敷くので、**腕の土台が板の厚さだけ高くなる**（STL から測って 7.2mm。S-2 の状態）。`sim/` の机の高さ・届く輪・つかむ高さが変わる（S-2 で STL から測って入れる）。
  - カメラの高さと向きは部品の形で決まり、人が変えられない。点検役は STL の面の向きから「カメラの板は水平から 25° ほど傾き、高さは 37cm ほど」と推定した。書き手が STL の差し込みの形から組んだところ、傾きは 25.0° で合ったが、高さは机から約 53cm だった（4 個の STL は組んだ位置に置かれておらず、中と上を 188mm 上げて差し込む。S-2 の状態）。**傾いていると、14mm のピースの上の面は、机の面として読んだ位置から 14 × tan(その点を見る光線の、真下からの角度) ずれる**。光線の角度はカメラの軸の傾きと同じではなく、点ごとに違う：輪の前半分で 0.5〜33.5°、ずれは 0.1〜9.3mm（盤の真ん中で 20.8°・5.3mm。S-3 の状態）。V-3 の余りより大きい所がある。だから K5 で、カメラの姿勢を出し、ピースの上の面の高さで写す。
  - 盤とピースの置き場が画面に入るか、腕が待つ姿勢でピースを隠さないかは、刷る前に `sim/` で確かめる（S-3）。

https://github.com/TheRobotStudio/SO-ARM100/tree/main/Optional/SO101_Wrist_Cam_Hex-Nut_Mount_32x32_UVC_Module

### 03 の撮影台との関係

[03 撮影台とカメラ](../目的別/03_撮影台とカメラ.md) の 3 案に、4 つ目として「本家の上のカメラの台（刷る）」を足す。パズルの線では 4 つ目を推す。ACT の「立方体を箱へ」は 03 のどれでもよい。2 つの課題は違うので、カメラの位置をそろえる必要は無い。ただ、同じ台を使えば、作る台が 1 つで済み、撮影台を組み替える手間も無い。

## それで何をするか（`sim/` に入れて決めること）

1. **刷る前に、カメラの位置を確かめる**：本家の上の台で、盤とピースの置き場が全部写るか、腕で隠れないか（S-3）。写らないなら、盤を小さくするか、台を変える。
2. **ピースの寸法を決める**：許せるずれ（S-8）と、実機の誤差（K1）を比べ、すき間とブロックの辺を決める（[計画書_シミュレーション](計画書_シミュレーション.md) の U-4 に答える）。
3. **ピースを刷る**：S-7 の STL。
4. **ピースを見つける道具を、実物の前に試す**：S-9 の正解付きの絵で。
5. **実機に流す動きを作る**：`sim/` の関節の列（S-6）→ LeRobot の角度。流す前に、換算した角度を `sim/` に戻して当たりと高さを見る。
6. **実機の動きを見直す**：記録した関節の動きを `sim/` で再生して、どこでずれたかを見る（S-11）。
7. （後の段）学習と比べる：A（スクリプト）と B（方策）を、同じ置き方・同じ回数で 05 の決め方（Fisher）で比べる。
