# 2026-11-20　品種切替をまたぐ完了信号を再生する

生産技術者と設備保守担当向けの提案。品種替え後に指令番号を再利用すると、前の品種の遅延応答を新しい指令の完了と解釈する可能性がある。既存の重複イベント検査に、品種切替と信号再生を組み合わせる。機種別の信号仕様を受け取る前に、期待する応答の意味を営業技術の受入表へ書ける。[実行計画](計画書_産業用フィジカルAIと事業化.md)

## 手元で確かめた範囲

模擬入力で旧指令を (41,1)、新指令を (42,1) とした。組は品種切替の世代と指令番号。新指令の待機中に届いた列から、最初に条件を満たす応答を受理する。Pythonで次の5列を列挙した。

|到着列|指令番号だけ|世代も一致|
|---|---|---|
|なし|待機|待機|
|旧|旧を誤受理|待機|
|新|新を受理|新を受理|
|旧→新|旧を誤受理|新を受理|
|新→旧|新を受理|新を受理|

これは信号の帰属の試験で、排除の成否は別途、画像と個体の正解で採点する。5列は境界を試す選定例。発生頻度は測っていない。旧応答に受信側が現世代を付ける場合と、再起動で同じ組を再使用する場合は、世代照合でも区別できない。

## Claude の次の一件

架空セルの担当へ、この5列と上記2反例を渡す。送信時の識別子を応答が保持できるか、再起動をまたいで一意かを、CRXとデンソーそれぞれの設備・PLC仕様で確認する。未確認の場合は「帰属不明」として保留する模擬動作を比較する。採用の目安は、模擬ケースで旧応答の誤受理がなく、新しい正当な応答を受理でき、保留による停止時間を記録できること。実機側の対応可否は未確認。
