# 2026-11-22　排除箱の基準を画像で読み、取付ずれと位置ずれを見分ける

設備保守と品質保証向け。パズル側では、カメラ姿勢の誤りが置き直しにも確認にも効き、画面上の読みが改善しても真のずれが悪化した。架空の排除セルでは、排除箱に固定した目印をワークと同じ画像で読み、箱に対する位置を確認する案を試す。品種替えや清掃で箱を置き直した後の復旧確認に使えるかを調べる。[パズルの検証](../../sim/README.md)・[排除セル](../../industrial/README.md)

## 数値モデルで確かめたこと

一次元の位置だけを扱った。箱中心からの真のずれは 0、±5 mm、カメラの共通ずれは 0、±5 mm、ワークの検出誤差は 0、±1 mm。全27条件を列挙した。判定は ±2 mm 以内を位置合格とする【試験用】。

| 方式 | 正しい合格 | 正しい不合格 | 誤合格 | 誤不合格 |
|---|---:|---:|---:|---:|
| 固定のカメラ座標 | 3 | 12 | 6 | 6 |
| 同じ画像の箱の基準との差 | 9 | 18 | 0 | 0 |

箱の目印が欠けた例は保留。目印が箱に対して 5 mm 動き、ワークも同じ向きへ 5 mm ずれた例では、差が 0 mm になり誤合格した。正常なワークも −5 mm と読まれ誤不合格になる。カメラの傾きによる差分が −3 mm 残ると、真の +5 mm は +2 mm と読まれ、単純判定では誤合格になる。位置だけでは対象個体を確認できないため、排除の完了には既存の個体照合も要る。

境界を追加し、基準との差を取った後の真のずれ 0、±2、±3、±5 mm と残差 0、±1 mm の21条件を比較した。±2 mm でそのまま判定すると誤合格2件・誤不合格2件。残差の上限を 1 mm と仮定し、観測の絶対値が 1 mm 以下で合格、3 mm を超えれば不合格、その間を保留にすると、誤判定0件・保留8件になった。現場で使う上限と許容誤差は未測定。

## 再現

~~~python
from itertools import product
from collections import Counter

def outcome(actual, measured):
    if measured is None:
        return "hold"
    truth, accepted = abs(actual) <= 2, abs(measured) <= 2
    return {(True, True): "pass", (False, True): "false_pass",
            (True, False): "false_reject", (False, False): "reject"}[truth, accepted]

relative, absolute = Counter(), Counter()
for actual, camera_shift, local_error in product((0, -5, 5), (0, -5, 5), (0, -1, 1)):
    part_pixel_in_mm = actual + camera_shift + local_error
    reference_pixel_in_mm = camera_shift
    absolute[outcome(actual, part_pixel_in_mm)] += 1
    relative[outcome(actual, part_pixel_in_mm - reference_pixel_in_mm)] += 1
print("absolute", dict(absolute))
print("relative", dict(relative))
print("missing reference", outcome(0, None))
print("loose reference", outcome(5, 5 - 5), outcome(0, 0 - 5))
print("differential bias", outcome(5, 5 - 3))

for lower, upper in ((2, 2), (1, 3)):
    tally = Counter()
    for actual, error in product((0, -5, 5, -3, 3, -2, 2), (0, -1, 1)):
        measured = abs(actual + error)
        decision = "accept" if measured <= lower else "reject" if measured > upper else "hold"
        tally[decision, abs(actual) <= 2] += 1
    print(lower, upper, sorted(tally.items()))
~~~

## Claude に渡す最小試作

架空セルの既存担当が追加するなら、既存の画像と真値を使って箱の位置判定だけを比較し、個体の正誤と混ぜずに採点する。まず平行移動、次に回転と高さの違い、目印の欠落・ずれ、隣の箱への入れ違いを初見として用意する。誤合格・誤不合格・保留、復旧までの時間を記録する。CRX・デンソー共通の成果物は、実機で使う判定値を決めるための撮影・採点票。
