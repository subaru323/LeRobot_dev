## P-001 フォロワーに力を入れる前に、目標位置を「いまの位置」に合わせる

- 中身:
  - 本家のコマンド（`lerobot-teleoperate`、`lerobot-record`、`lerobot-rollout`）でフォロワーを使うときは、**コマンドの 1 回ごとに、直前に** `python tools\prime_goal.py <フォロワーのポート>` を流し、`OK` を確かめてから始める。流した後は、フォロワーを動かさず、5V も抜かない。
  - 自分で書くプログラムでフォロワーに力を入れるときは、`tools\so101_common.py` の `torque_on_in_place()` を使う（目標位置を合わせてから力を入れる）。`SOFollower.connect()` を、目標位置を合わせずに呼ばない。
  - フォロワーを動かすプログラムは、利用者が作った姿勢から始める。動かす前に、モーターの速度と加速度に上限を付ける。
- 根拠: 確かめた（2026-10-28。目標位置を合わせずに `connect()` したら、腕が最高速度で跳ねて過負荷で止まった。`prime_goal.py` の後に `connect()` を呼ぶと、6関節とも 0 ステップだった。フォロワー単体、1 回）。利用者の判断（「動かすの速すぎるだろ」「初期姿勢作るから、その状態からプログラム始めて」、2026-10-28）。詳しくは [フォロワーの跳びと過負荷](../knowledge/フォロワーの跳びと過負荷.md)。
- 本家の各コマンドを通した場合に跳ばないかは、まだ確かめていない（[計画書](../plan/計画書_テレオペ以降.md) の前提 1〜1c）。
- 守れない所: 本家のコマンドは、つなぐときに加速度を最大（254）に書き直す（`feetech.py` の `configure_motors()`）。本家のコマンドを使う間は「加速度に上限を付ける」は守れず、速度の上限（`prime_goal.py`）と、評価での `--robot.max_relative_target` で代える。
- 最後に見直した日: 2026-10-28

## P-002 キャリブレーションは、保存の前に MIN/MAX を確かめる

- 中身: `lerobot-calibrate` で「端から端まで動かす」段階の後、Enter を押す前に、表の MIN と MAX を見る。MIN が 0 付近で MAX が 4095 付近の関節があったら、保存せずにやり直す（真ん中の姿勢がずれている）。
- 根拠: 確かめた（2026-10-28。たたんだ姿勢で Enter を押したとき、肩上げ・肘・手首曲げが 0〜4095 になった。数字の跳びを記録して、境目をまたいでいることを確かめた。姿勢を直して取り直したら、全部の関節が 2048 をはさむ範囲に収まった）。手順は [組み立て手順書](../組み立て手順書.md) STEP 5-6。
- 最後に見直した日: 2026-10-28
