# SO-ARM101 組み立て手順書（Windows + uv）

- 対象：SO-ARM101 Standard版（電源はすべて5V）
- 構成：フォロワー＝購入したプリント済み部品、リーダー＝自分でプリントした部品
- ゴール：リーダーを手で動かすと、フォロワーが同じ動きをする（テレオペ）
- 3Dプリントの手順はこの手順書には含めていません

## この版について（2026-10-15 確定）

- 照合した一次資料：本家 SO-101手順とインストール手順（lerobot 0.6.2、`main` のコミット `53feaef`、2026-10-14）、lerobot のソースコード（コマンドの表示文・エラー文・キャリブレーションの保存先）、Seeed Wiki（2026-03-11 更新版）、TheRobotStudio の部品表。手順書の中のリンクは、すべて開けることを確かめた。
- STEP 1 のインストール（`53feaef`、uv、Windows 11）は、この手順書を書いたパソコンの作業用フォルダで実際に通した。STEP 2〜8 のコマンドも、オプションの書き方が通ることを確かめた（基板が無いので、ポートに接続する手前まで）。
- 実機（アームと基板）では、2026-10-28 に STEP 2〜5（フォロワー）と、フォロワー単体の動作テストまで通した。そこで分かったことは各STEPと「困ったとき」に書き足し、安全ツールを「付録」にまとめた。STEP 6〜8（リーダーとテレオペ）は、まだ実機で通していません。実機で手順と違うことが起きたら、この手順書を直してください。
- 「未確認」と書いた所は、一次資料で確かめきれなかった所です。

## STEP 1　ソフトのインストール

### 1-1. Git

https://git-scm.com/downloads/win からダウンロードし、インストーラーは全部初期設定のまま進めます。

### 1-2. uv

PowerShellで次を実行します。

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

参考：https://docs.astral.sh/uv/getting-started/installation/

インストールが終わったら、**PowerShellを一度閉じて開き直して**ください。開き直さないと、次の 1-3 で「用語 'uv' は、コマンドレット…として認識されません」と出ます。

開き直したら、次を実行してバージョンが表示されるか確かめます。

```powershell
uv --version
```

開き直さずに続けたいときは、代わりに次を1回実行します（そのPowerShellの中だけ有効）。

```powershell
$env:Path = "$HOME\.local\bin;$env:Path"
```

### 1-3. LeRobot

```powershell
cd ~
git clone https://github.com/huggingface/lerobot.git
cd lerobot
git checkout 53feaef
uv venv --python 3.12
.venv\Scripts\activate
uv pip install -e ".[feetech,core_scripts]"
```

- Python 3.12 がパソコンに無ければ、uv が自動でダウンロードします（あれば、それを使います）。
- `feetech` はモーター用、`core_scripts` はキャリブレーションやテレオペのコマンド用です。
- `activate` で「スクリプトの実行が無効」と出たら、次を1回実行してから、もう一度 `activate` します。
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```
- `git checkout 53feaef` は、この手順書で確かめた版に固定するためです。LeRobot は更新が速く、新しい版ではコマンドが変わることがあります。「detached HEAD」という英語の表示が出ますが、問題ありません。
- 最後に次を実行し、`usage: lerobot-teleoperate ...` と表示されればインストール成功です。
  ```powershell
  lerobot-teleoperate --help
  ```

### 1-4. 次回以降の作業開始時

作業を始めるときは、毎回この2行を実行します。

```powershell
cd ~\lerobot
.venv\Scripts\activate
```

`~\lerobot` は、1-3 でホーム（`cd ~`）に clone した場合の場所です。別のフォルダに clone したときは、そのフォルダの中の `lerobot` に読み替えます。

行頭に `(lerobot)` のような表示が出ていれば準備完了です。

## STEP 2　ポートの確認

1. 基板1枚に、**5V電源とUSBの両方**をつなぎます（USBだけでは給電されません）。
2. 次を実行し、「Remove the USB cable from your MotorsBus and press Enter when done.」と出たら、USBを抜いてEnterを押します。
   ```powershell
   lerobot-find-port
   ```
3. 「The port of this MotorsBus is 'COM3'」のように表示されます。この番号を、テープで基板に書いておきます。USBは挿し直します。
4. もう1枚の基板でも同じことをします。

| 基板 | COM番号 |
|---|---|
| フォロワー用 | COM11（USBシリアル番号 5AE7044447） |
| リーダー用 | COM10（USBシリアル番号 5AE7049321） |

※ STEP 4 で、STEP 2 のときとは逆の基板をフォロワーに取り付けたため、入れ替えた。基板は2枚とも同じ物で、IDはモーター側に書き込まれているので、どちらの基板を使っても問題ない。基板のテープの番号も書き直す。

USBを別の差し込み口に挿すと、COM番号が変わることがあります。各基板は、毎回同じ差し込み口に挿してください。番号が変わったら、もう一度 `lerobot-find-port` で確かめます。

※ この手順書では、フォロワー＝`COM3`、リーダー＝`COM4` として書いています。自分の番号に読み替えてください。
※ パソコンによっては、COM3・COM4 などを Bluetooth（「Bluetooth リンク経由の標準シリアル」）が使っています。その場合、基板には別の番号が付きます（実機では COM10・COM11 だった）。

### COMポートが出てこない場合

- デバイスマネージャーを開き、「ポート（COMとLPT）」を確認します。
- 表示されなければ、基板のUSBチップ用のドライバを入れます。Waveshare製の基板なら、WCHのCH343ドライバです（実機で確認：USB ID は VID_1A86&PID_55D3。Windows 11 では標準ドライバの「USB シリアル デバイス」としても認識された）。
- デバイスマネージャーの「ユニバーサル シリアル バス コントローラー」にも何も増えないときは、ドライバではなくUSBの接続の問題です。充電専用のUSB-Cケーブルでないか、奥まで挿さっているかを確かめます（実機では、挿し直して認識された）。
  WCH公式：https://www.wch-ic.com/downloads/CH343SER_EXE.html
- **Waveshare製の基板の場合**は、ジャンパー2個が「B」側（USB）になっているか確認します。

## STEP 3　モーターにIDを書き込む（組み立て前）

**最初に動画を1回見てから作業してください。**
https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/setup_motors_so101_2.mp4

### 3-1. フォロワー

```powershell
lerobot-setup-motors --robot.type=so101_follower --robot.port=COM3
```

### 3-2. リーダー

```powershell
lerobot-setup-motors --teleop.type=so101_leader --teleop.port=COM4
```

### 3-3. やり方（両方共通）

1. 「Connect the controller board to the 'gripper' motor only and press enter.」と表示されます。
2. **そのモーター1個だけ**を、3ピンケーブルで基板につなぎます。ほかのモーターとはつながないでください。
3. Enterを押すと、IDが書き込まれ、「'gripper' motor id set to 6」と表示されます。
4. 書き込んだモーターに、テープで番号（F6、L6など）を書きます。
5. 3ピンケーブルは、**基板側だけ抜き、モーター側は挿したまま**にしておきます（組み立てでそのまま使えます）。
6. 次のモーターに新しい3ピンケーブルを挿して基板につなぎ、同じことを繰り返します。

| 順 | 関節 | ID | フォロワー | リーダー |
|---|---|---|---|---|
| 1 | gripper | 6 | [x] F6 | [x] L6（C046） |
| 2 | wrist_roll | 5 | [x] F5 | [x] L5（C046） |
| 3 | wrist_flex | 4 | [x] F4 | [x] L4（C046） |
| 4 | elbow_flex | 3 | [x] F3 | [x] L3（C044） |
| 5 | shoulder_lift | 2 | [x] F2 | [x] L2（C001） |
| 6 | shoulder_pan | 1 | [x] F1 | [x] L1（C044） |

6個目が終わると、コマンドは自動で終わります。

### 3-4. 注意

- リーダーは、**型番シールを見て表のとおりのモーターをつなぐ**こと。ギア比を間違えると、リーダーが重くなったり、自重で垂れたりします。
- 3ピンケーブルを抜き差しするときは、**先に5V電源を抜き**、差し終えてから電源を戻してEnterを押します（Seeedの安全上の注意）。USBは挿したままにします。
- エラーが出たら、電源、USB、3ピンケーブルの3つが抜けていないか順に確認します。作業中に電源ケーブルが抜けやすいので、Enterを押す前に毎回確認してください。

## STEP 4　フォロワーの組み立て（購入品の部品）

### 4-1. ネジの使い分け

| ネジ | 使う場所 |
|---|---|
| M2×6mm（一番小さいネジ） | モーター本体を部品に固定する、モーターホルダーを固定する |
| M3×6mm | ホーン（上側）の固定、アーム部品どうしの固定 |

### 4-2. 共通のルール

- ホーンは上下2枚付けます。**ネジで留めるのは上側だけ**で、下側はネジ不要です。
- ホーンを付ける順番は、関節によって違います。
  - 関節1〜4：**モーターを部品に入れる前に**、ホーンを付けておきます。
  - 関節5とグリッパー：**モーターを部品に入れてから**、ホーンを付けます。
- 手首（関節5）だけは、ホーンが1枚です。
- モーターを部品にはめたら、組み進める前に**3ピンケーブルを挿しておきます**。組んだ後だと挿しにくくなります。
- **F1〜F6のテープを見て、正しい関節に入れているか**確認しながら進めます。
- 文字だけで分かりにくいときは、動画か、Seeedの工程写真（「Assemble Follower Arm」の Step 1〜17）を見ます。

## STEP 5　フォロワーのキャリブレーション

動画：https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/calibrate_so101_2.mp4

```powershell
lerobot-calibrate --robot.type=so101_follower --robot.port=COM3 --robot.id=follower1
```

1. アームをクランプで机に固定します。
2. 電源とUSBをつなぎます。
3. コマンドを実行します。モーターの力が抜けるので、アームが倒れないよう手で支えます。
4. 画面に姿勢の図が出ます（図では、上腕がまっすぐ立ち、前腕が水平に前を向いています）。画面の図と動画に合わせて、全関節を可動範囲の**真ん中あたり**に手で合わせてからEnterを押します。
   - **たたんだ休止姿勢のままEnterを押さないこと。** 上腕を真上に起こし、前腕を水平に前へ、手首を前腕と一直線にします。
   - 前腕は力が抜けていて垂れるので、片手で水平に支えたまま、もう片方の手でEnterを押します。姿勢が合っている必要があるのはEnterの瞬間だけです。数度のずれは問題ありません。
5. 「Move all joints except 'wrist_roll' …」と出たら、**手首回転（wrist_roll）以外**の各関節を、1つずつ**端から端まで**ゆっくり動かします。手首回転は動かさなくてかまいません（表にも出ません）。グリッパーは全開から全閉まで動かします。
6. Enterを押す前に、表のMIN/MAXを確かめます。どの関節も、2048をはさんで両側に広がっていれば正常です（実機の例：肩の回転 697〜3362、肩上げ 825〜3207、肘 846〜3038、手首曲げ 825〜3164、グリッパー 1992〜3411）。**MINが0付近で、MAXが4095付近になっている関節があったら失敗です**（4の姿勢がずれていた）。`Ctrl + C` で止めて、やり直します。
7. 問題なければEnterを押します。「Calibration saved to …」と出れば完了です。

**注意**：`--robot.id=follower1` の名前は、今後もずっと同じものを使ってください。キャリブレーション結果がこの名前で保存されます。

## STEP 8　テレオペで動作確認（ゴール）

動画（Seeed Wiki に載っている動画）：https://www.youtube.com/watch?v=hnRwfcyX1ZI

### 8-1. 実行前の安全確認

- [ ] 2台ともクランプで机に固定している
- [ ] フォロワーの周囲1m以内に、物と人がいない
- [ ] 2台とも電源とUSBがつながっている
- [ ] リーダーを、フォロワーと同じ姿勢にしてから始める（始めた瞬間、フォロワーがリーダーの姿勢へ一気に動くため）

**なぜ一気に動くのか（実機で確認）**：LeRobotはつないだ瞬間にフォロワーのモーターに力を入れ、モーターに残っている「目標位置」へ**最高速度で**向かわせます。キャリブレーションをやり直した後などは、この目標位置がまったく別の角度を指していることがあり、腕が跳ねて過負荷エラーになりました。そのため、**初回は 8-2 の安全版から始めます。**

### 8-2. 実行（初回は安全版）

1. 2台の姿勢のずれを確かめます（どちらにも力は入りません）。`<<<` が付いた関節は、リーダーをフォロワーの姿勢に近づけます。全部の行から `<<<` が消えたら `Ctrl + C` で止めます。
   ```powershell
   python tools\compare_pose.py
   ```
2. 安全版のテレオペを始めます。
   ```powershell
   python tools\safe_teleop.py
   ```
   - 「Support the FOLLOWER…」と出たら、フォロワーを手で支え、リーダーは動かさずにEnterを押します。フォロワーは**その場で**力が入り、跳びません。
   - フォロワーがリーダーの姿勢まで**ゆっくり**（1秒に約30°）近づきます。その間、リーダーは動かしません。
   - 「Caught up -> following the leader」と出たら、リーダーを動かします。フォロワーの1回の動きには上限が付いています（1秒に約120°まで）。キャリブレーションで決まった範囲の外へは動きません。
   - どれかのモーターに強い負荷が1秒続くと、自動で止まります。
3. 止めるときは `Ctrl + C` を押します。フォロワーは**その姿勢のまま力を保ちます**。「SUPPORT THE FOLLOWER…」と出たら、手で支えてからEnterを押すと力が抜けます。

本家のコマンドで動かすときは、次のとおりです。安全版で問題なく動くことを確かめてからにします。始める直前に、必ず 1 の `compare_pose.py` でずれを小さくし、**続けて `python tools\prime_goal.py` を流します**（フォロワーの目標位置を「いまの位置」に合わせ、速度に上限を付ける。流してから本家の接続を通しても、フォロワーが動かないことをフォロワー単体で確かめた。2026-10-28）。流した後は、フォロワーを動かさず、5V も抜かずに、すぐ本家のコマンドを始めます。

```powershell
lerobot-teleoperate --robot.type=so101_follower --robot.port=COM3 --robot.id=follower1 --teleop.type=so101_leader --teleop.port=COM4 --teleop.id=leader1
```

### 8-3. 確認

| 確認項目 | 確認 |
|---|---|
| リーダーの肩を回すと、フォロワーの肩も同じ向きに回る | [ ] |
| 肩上げ、肘、手首曲げ、手首回転も同じように追従する | [ ] |
| トリガーを動かすと、それに合わせてグリッパーが開閉する | [ ] |
| 異音、振動、急な動きがない | [ ] |

止めるときは `Ctrl + C` を押します。**止めるとフォロワーの力が抜けて、腕が自重で倒れます。** 先にリーダーで、フォロワーを机の近くの低い姿勢まで下ろしてから止めるか、フォロワーを手で支えながら止めてください。
異常な動きや異音があったら、**すぐ電源を抜いてください**（このときも腕は倒れます）。

- [ ] STEP 8 完了 🎉

## 困ったとき

| 症状・エラー | 対処 |
|---|---|
| `lerobot-...` が見つからないと言われる | STEP 1-4 の2行（`cd ~\lerobot`、`.venv\Scripts\activate`）を実行したか確認する |
| COMポートが出てこない | STEP 2 の「COMポートが出てこない場合」を参照 |
| `Could not detect the port`（ポート確認のとき） | USBを抜いてからEnterを押したか、途中でほかのUSB機器を抜き差ししていないか確認し、やり直す |
| `Could not connect on port` | COM番号が合っているか確認する。ほかのソフト（Arduino IDEなど）がポートを使っていたら閉じる |
| `Motor 'gripper' (model 'sts3215') was not found` | 電源、USB、3ピンケーブルの抜けを確認する。電源は5Vアダプタか確認する |
| `Failed to sync read 'Present_Position'` | 電源が入っているか、3ピンケーブルが緩んでいないか確認する。LEDが消えているモーターがあれば、その手前のケーブルを疑う |
| `Magnitude ... exceeds 2047` | 電源を入れ直してキャリブレーションをやり直す（STEP 5-4 の真ん中の姿勢を、図と動画で取り直す）。直らなければSeeedのサーボ調整ツールを使う（ https://wiki.seeedstudio.com/lerobot_steering_gear_debugging_tool ） |
| キャリブレーションで MIN が0付近、MAX が4095付近になる | Enterを押したときの姿勢が、真ん中から大きくずれている（たたんだ姿勢など）。STEP 5-4 のとおり、上腕を立て、前腕を水平に支えてからEnterを押し直す |
| `Overload error`（過負荷）が出る。止めた後も一部の関節が手で動かない | 腕が急に動いて、モーターが過負荷の保護で止まっている。力を抜く指示も、エラーのモーターから先には届いていない。**5V電源を抜き、5秒待ってから挿し直す**（エラーと力がリセットされる）。モーターが熱くないか、焦げたにおいがないかも確かめる。その後、`python tools\scan_arm.py` で6個の返事を確かめる |
| つないだ瞬間にフォロワーが跳ねる | STEP 8-1 の「なぜ一気に動くのか」を参照。`tools\safe_wiggle.py` や `tools\safe_teleop.py` を使う |
| フォロワーの動きがリーダーとずれる | キャリブレーションをやり直す（下を参照） |
| キャリブレーションをやり直したい | 同じキャリブレーションのコマンドを実行し、「Press ENTER to use provided calibration file … or type 'c'」と出たら `c` を入力してEnter。または `C:\Users\（ユーザー名）\.cache\huggingface\lerobot\calibration\robots\so_follower\follower1.json`（リーダーは `…\calibration\teleoperators\so_leader\leader1.json`）を削除してから実行する |
| 部品やモーターを交換した | 上と同じ方法で、交換したアームのキャリブレーションをやり直す |
| それでも解決しない | LeRobot Discord（英語）： https://discord.com/invite/s3KuuzsPFb |

## 付録　安全ツール（`tools` フォルダ）

実機で作業したときに作った、LeRobot の上で動く小さなプログラムです。この手順書と同じ階層の `tools` フォルダに入っています。

| ファイル | 内容 | モーターは動くか |
|---|---|---|
| `so101_common.py` | ほかのツールが使う共通部分。**この机のCOM番号**（`FOLLOWER_PORT`、`LEADER_PORT`）とID（`follower1`、`leader1`）は、ここに書いてある | — |
| `scan_arm.py COMx` | 6個のモーターが、ID 1〜6で返事をするか確かめる | 動かない |
| `safe_wiggle.py [COMx] [角度]` | フォロワーを、いまの姿勢から1関節ずつ±10°（初期値）ゆっくり動かして戻す | 動く（ゆっくり） |
| `compare_pose.py [--once]` | リーダーとフォロワーの関節角度を並べて、ずれを表示する | 動かない |
| `safe_teleop.py` | 跳ばずに始まり、速さに上限を付けたテレオペ（STEP 8-2） | 動く |
| `prime_goal.py [COMx] [--speed 2000]` | 本家のコマンド（`lerobot-teleoperate`、`lerobot-record`、`lerobot-rollout`）の直前に流す。フォロワーの目標位置を「いまの位置」にし、速度に上限を付ける。5V を抜くと消える | 動かない |
| `servo_common.py`、`servo_play.py`、`servo_gui.py`、`servo_mirror.py` | 腕に組み込んでいない STS3215 を 1〜2 個で動かす（2026-11-16 追加）。モーターが 3 個以上返事をすると、腕とみなして動かさない。使い方は [02 モーター1個で遊ぶ](目的別/02_モーター1個で遊ぶ.md) | 動く（ばらのモーターだけ） |
| `camera_check.py` | カメラを全部同時に開いて、実際の fps を測り、狙いを付ける画像を保存する（2026-11-16 追加）。[03 撮影台とカメラ](目的別/03_撮影台とカメラ.md) | 動かない |
| `eval_log.py` | 評価の順番を決め、結果を打ち込み、条件ごとにまとめる。LeRobot を読み込まない（2026-11-16 追加）。[05 汎化テスト](目的別/05_汎化テスト.md) | 動かない |
| `v070\peek_dataset.py` | v0.7.0 の練習の環境で、Hub のデータを落とさずに中身を見る（2026-11-16 追加）。[08](目的別/08_実機なしで練習_v070.md) | 動かない |
| `remote\server_so101_front_wrist.yaml` | 遠隔推論のサーバーの設定の雛形（2026-11-16 追加、未確認）。[07](目的別/07_推論を別のパソコンで.md) | — |

安全のための仕組み（`safe_wiggle.py` と `safe_teleop.py` の共通点）は次のとおりです。

- 力を入れる前に、モーターの目標位置を「いまの位置」に合わせる（跳ばない）。
- モーターの速度、加速度、力に上限を付ける（グリッパーの力は最大の半分まで。LeRobot と同じ）。
- キャリブレーションで決まった範囲の、端から5°手前までしか動かさない。
- 負荷が大きいと止まる。止まった後は姿勢を保ち、**手で支えてからEnter**で力が抜ける。
- 動かす前に、全部のモーターのエラーの状態とキャリブレーションを確かめる。問題があれば、動かさずに止まる。

使い方：STEP 1-4 の2行で作業を始めてから、この手順書のフォルダの1つ上（`docs` と `tools` があるフォルダ）で実行します。

```powershell
python tools\scan_arm.py COM3
```

COM番号やIDを変えたときは、`tools\so101_common.py` の先頭の4行を書き換えます。
