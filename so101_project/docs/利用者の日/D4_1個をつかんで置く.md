## 止める条件と戻し方

- 腕が跳ぶ・うなる・熱い・柱やカメラに近づく・ピースを押しつぶしそう：**Ctrl+C**。道具はその姿勢で腕を保ち、「SUPPORT THE ARM」と出る。**腕を手で支えてから** Enter。それでも危ないときは、腕を支えながら 5V を抜く。
- 爪以外の関節に重さがかかりすぎると（負荷 600）、道具が自分で止まる。そのときも支えてから Enter。
- 関節のサーボは、熱・負荷・電圧で**自分を守って急に力を失う**ことがある（その関節が垂れる）。道具は動いている間 0.5 秒ごとにサーボの状態を読み、「motor error status ... while moving」で止まる。それまでの間は腕が垂れるので、**動いている間は腕の下に手を添える**。止まったら支えて Enter、5V を抜いて差し直してから次へ。爪は、閉じるときに負荷が 350 を超えると**閉じるのをやめるだけで、止まらずに続く**（`puzzle_run.py` の決まり。挟む力をかけ続けないため）。ピースを押しつぶしそうなら Ctrl+C。
- 空中の回で止まった：机の高さで流さない。Claude が記録を読む。
- 紙・合板・カメラが動いた：D3 の 3〜5 をやり直す。
- 道具が自分で止まる（2026-11-23 から足したもの。[sim/README](../../sim/README.md) の S4）：カメラが前と同じ絵を返した（固まった）・絵が来ない・爪が空・終わりの上の絵で置いた所が外れ・ピースがもう盤の上にある（前の回が途中で止まった盤のまま。出る文は「plan: 解けない: ピース L が盤に重なる ... -> real arm: a piece already lies on the board」か「already lies at its board target」）。どれも、止まったら支えて Enter。
- 力を入れる前後に「There is no status packet」で止まった：基板の返事が 1 回欠けた（線のゆるみ・電源）。限界と力を入れる書き込みは、返事が 1 回欠けるだけで止まる作り（S4-04。慎重すぎるが安全の側）。腕を支えて Enter、線と 5V を確かめてから、腕を写す姿勢に持って流し直す。続けて出るなら線を替える。**止まった後に、同じコマンドをそのまま流し直さない**：Claude が記録を読み、ピースを置き場に戻し、腕を写す姿勢に持ってから流す。
- 流し始めに「the motors still hold the arm」と出た：前の回がきれいに終わらなかった（PC・道具が落ちた、ケーブルが抜けた）。**腕を支えてから** Enter（力が抜ける）。そのあと道具は始めの姿勢かを見て、外れていれば力を入れずに止まる。
- 流し始めに「motor error status」で止まった：サーボが自分を守って止まった印が残っている。5V を抜いて差し直してから（そのあと [P-001](../rules/RULES.md) の手順。`puzzle_run.py` は力を入れる前に目標を今の位置に合わせる）。
- 通信が切れて止まると、力を抜けずに「could not release torque ... unplug the 5V power」と出ることがある：**腕を支えながら 5V を抜く**。
