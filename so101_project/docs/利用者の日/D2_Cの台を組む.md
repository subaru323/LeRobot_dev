## 2. 合板に印を付ける（30 分）

座標は [C の台の設計](../../hardware/C_台の設計.md) の向き：+x が腕の前、+z が腕の右（腕の後ろから見て）。合板は x −80〜420（500mm の辺）・z −300〜300（600mm の辺）。下の「後ろの端から」は x = −80 の端からの長さ、「左の端から」は z = −300 の端からの長さ（設計の値から引き算した。測ってはいない）。

| 印 | 後ろの端から | 左の端から |
|---|---|---|
| 腕の前の線（z = 0。腕の向き） | 500mm の辺に平行な線 | 300 |
| 腕の肩の回る軸（`shoulder_pan` の軸。x = 38.8） | 118.8 | 300 |
| 腕の土台の後ろの縁（x −22.4）【仮】 | 57.6 | — |
| 柱の中心（x 353.3・z 19.5） | 433.3 | 319.5 |
| レンズの先の真下（x 157.3・z 19.5） | 237.3 | 319.5 |

1. 合板を机に平らに置き、上の印を鉛筆で写す。型紙があれば、型紙を合板の端に合わせてテープで留め、上から写す。型紙を使うときは、次の順にする。(a) 3 枚目（後ろから 1 段目・左から 3 列目）の下の太い線を、合板の後ろの端に合わせる（紙の端ではない。紙のまわりには刷れない余白が 15mm ある）。(b) 黒い太い縦の線 2 本のうち左の 1 本（腕の前の線 z 0。格子の字が「x… z0」の所を通る）が、合板の左の端から 300mm になるように、前と後ろの 2 か所を鋼の定規で測って置き、テープで留める。(c) 7 枚目（後ろから 2 段目・左から 3 列目）を、3 枚目と 34mm 重ねて、重なる所の格子の数字（x150・x200 など）と線を合わせて留める。(d) 印を針で刺すか、鉛筆で写す。(e) 型紙を外す前に、合板に「前」と鉛筆で書く。(f) 最後に、上の表の「後ろの端から・左の端から」を鋼の定規かメジャーで測って確かめる（型紙の字は板の座標 x・z で、表の数は端からの長さ。どちらも `hardware\make_template.py selftest` で同じ点と確かめた）。

## 5. 柱を立てる（1 時間）

1. 柱（575mm）の下の端の 4 つの面に、角の金具を 1 個ずつ、後から入れられる T ナットと M5 ネジで仮に付ける。
2. 柱の中心を 2 の印に合わせて立て、金具を木ねじで合板に留める（4 個）。
3. 直角定規を合板に立てて、柱が 2 つの向き（x と z）とも真っ直ぐ立っているかを見る。傾いていれば金具のネジをゆるめて直し、締める。
4. 柱の面が、2 で引いた x の向きの線と平行になるように（吊る腕の向きがこれで決まる）。

## 6. 吊る腕を付ける（30 分）

1. 吊る腕（281mm）を柱の上の端に載せる。吊る腕は**腕の方（−x）へ真っ直ぐ**、2 で引いた x の向きの線の真上に向ける。
2. 吊る腕の端は、柱の外の面（腕から遠い面）から **35mm 先まで出す**（柱の両側の角に金具を付けるため）。
3. 柱の両側（腕に近い側と遠い側）の角に、金具を 1 個ずつ付ける。
4. 下げ振りかメジャーで、吊る腕の腕の側の端が、2 の x の向きの線の真上にあるかを見る（ずれていれば、柱の向きを 5 の 4 で直す）。
