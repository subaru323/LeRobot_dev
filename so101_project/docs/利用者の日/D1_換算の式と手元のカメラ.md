## 1. 電源の確かめ（5 分）

[組み立て手順書](../組み立て手順書.md) STEP 0 の電源の表（アダプタ 2 個の銘板が 5V・フォロワーのモーターが C001・12V のアダプタをしまった）にチェックを付ける。

## 2. 手首の台を付ける（30 分）

1. 5V と USB を抜く。
2. [準備手順書](../準備手順書.md) の C-3 の 1〜4 をする（F6 を外し、ナットを押し込み、F6 を戻し、台をネジで留める。カメラはまだ付けなくてよい）。
3. 5V と USB を差す。F6 を外したので、キャリブレーションが合っているかを確かめる。腕を**肘を少し曲げ、机にも土台にも触れない空中の姿勢**に手で持ち、Claude に「流して」と言う（たたんで机に当てた姿勢だと、負荷で途中で止まる）。Claude がタブで次を流す：

```
C:\Users\genes\Documents\PROJECTS\lerobot\MAIN_PG\lerobot\.venv\Scripts\python.exe C:\Users\genes\Documents\PROJECTS\lerobot\tools\safe_wiggle.py COM11 10
```

4. **Enter は 2 回。** 1 回目：その姿勢のまま Enter → 力が入って腕が止まり、**1 秒ほどで、手を離さなくても**各関節が ±10° ずつゆっくり動いて戻る（Enter の前に、支える手は軽く添えるだけにしておく。2026-11-19 に点検 C42b の 2 で直した）。2 回目：最後に「SUPPORT THE ARM」と出たら、**腕を手で支えてから** Enter（力が抜けて腕が落ちるため）。
5. 爪が開き閉じし、どの関節も跳ばなければよい。おかしければ止めて Claude に言う（キャリブレーションをやり直してから 3 へ。やり直すと、3 の結果はやり直した後のものでないと使えない）。

## 3. K1 の (1)(2)：角度の換算の式（30〜60 分。力は抜いたまま）

腕は自分では動かない。画面の英語の指示に従って、手で動かして Enter を押す。**始める前に、下の 2）基準の姿勢を先に読んでおく**（1）の画面にも「基準の姿勢の近くに置いて」と出る）。

```
C:\Users\genes\Documents\PROJECTS\lerobot\MAIN_PG\lerobot\.venv\Scripts\python.exe C:\Users\genes\Documents\PROJECTS\lerobot\tools\k1_calib.py COM11
```

「上腕」は、肩（shoulder_lift）と肘のモーターのホーン（回る丸い所）の中心を結ぶ線のこと。上腕の部品の外の形は、この線から 14° ほど傾いているので、外の形で角度を合わせない（許せるのは 15° まで）。

1）**関節の向き（5 回）**：基準の姿勢の近くに置いて Enter → 言われた 1 つの関節だけを、言われた向きに 20〜30° 手で回して Enter。**回さない関節は、もう一方の手で押さえる**（力が抜けているので、重さで一緒に動く。ほかの関節が回した角度の半分より動くと「again」と出て、やり直しになる）。

2）**基準の姿勢（1 回）**：腕をまっすぐ前、上腕は真上、前腕は水平、爪は真下、動く爪が前、手首の台（付けていれば）が左。この形で手で支えて Enter。

3）**確かめの姿勢（1 回）**：上から見て腕を時計回りに 90° 回す（腕が自分の右を向く）。上腕を（ホーンを結ぶ線で）その向きへ 45° 倒す（土台から離れる向き）。前腕は水平、爪も水平で土台から遠い向き。動く爪は、基準の姿勢で腕が向いていた側（ロボットの前の側）。手首の台（付けていれば）は手首の下。手で支えて Enter。予想と 15° より違う関節があると、ファイルを書かずに止まる（向きか基準の姿勢の取り方がまずいため。後で腕が机に当たるのを防ぐ）。そのときは最初から流し直す。

4）**爪**：手で全部閉じて Enter → 幅の分かる物を爪ではさみ、その幅（mm）を打って Enter。小さい物から大きい物まで 2〜3 回。何も打たずに Enter で終わる。

5）終わると `sim\calib\k1_follower1.json` に書かれる（中に `"verified": true`）。Claude に「終わった」と言う。Claude が `sim/` で格子の 11 点の段取り表を作る（`node tools/k1-plan.js --k1 calib/k1_follower1.json`。腕は動かない）。格子の点へ実際に動かす K1 の (3)(4)（`k1_run.py`）は、腕と柱を載せる板ができてから D3 でする。

## 4. 手元の USB カメラを確かめる（40 分。腕は使わない）

目的：上のカメラに使えるか（盤の角まで入るか・細かさ）を決めて、買う物を減らす。**絵は 1 回撮るたびに Claude に言う**（同じ名前のファイル `cam<番号>.png` に上書きされるので、Claude がその場で別の名前に写す）。

1. 2 台をパソコンの別々の USB の口に差す。番号を調べる：

```
C:\Users\genes\Documents\PROJECTS\lerobot\MAIN_PG\lerobot\.venv\Scripts\lerobot-find-cameras.exe opencv --output-dir C:\Users\genes\Documents\PROJECTS\lerobot\outputs\captured_images
```

2. Claude が写った絵を見て、下の表を埋める。パソコンに内蔵のカメラが写っていたら、その番号は使わない。

| 番号 | どのカメラか（型番。本体のシールか箱） |
|---|---|
| | |
| | |

3. **画角**：方眼の紙（かメジャー）を机に置く。カメラを箱か本に載せて真下に向け、テープで留める（手で持つと、つないでいる間と 5 秒の測りの間に動く。絵は最後の 1 コマ）。紙の**上と下の端が、絵の中に入る**高さにする（20cm 前後）。**レンズの面から**紙までの高さを測る。1 台ずつ、次を流す（`0` はそのカメラの番号）：

```
C:\Users\genes\Documents\PROJECTS\lerobot\MAIN_PG\lerobot\.venv\Scripts\python.exe C:\Users\genes\Documents\PROJECTS\lerobot\tools\camera_check.py 0 --width 1920 --height 1080 --fourcc MJPG --fps 5 --seconds 5
```

   絵は `outputs\camera_check\cam0.png` に出る。Claude に「高さ ○cm」と言う。Claude が絵の上下と左右の目盛りを読み、縦と横の画角を出す。止まったら、`--fps 15`、次に `--fourcc` を外して試す。それでも 1920×1080 で動かなければ、`--width 1280 --height 720`、次に `--width 640 --height 480`。**どの大きさで動いたかを控える**（画角は、使う大きさの絵で測ったものしか使えない。小さい大きさでは、素子の真ん中だけを使うことがある）。

4. **色**（あれば）：刷ったピースか色紙を机に並べ、部屋のいつもの明かりで、3 と同じコマンドで撮る（そのたびに Claude に言う）。窓の光が入る時間と、夜の明かりの 2 回あるとよい（W5 の試しに使う）。
