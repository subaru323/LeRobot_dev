## どの段でも守ること

- **自分たちの道具**（`safe_wiggle.py`・`k1_calib.py`・`safe_teleop.py`・`puzzle_run.py`・`k1_run.py`）：腕が跳ぶ・うなる・熱いときは **Ctrl+C**。道具はその姿勢で腕を保つ。「SUPPORT THE ARM」（か「SUPPORT THE FOLLOWER」）と出たら、**腕を手で支えてから** Enter。危ないときは支えながら 5V を抜く。細かくは [実機日の一枚](実機日の一枚.md) の「どの日も同じ中止の決まり」。
- **本家のコマンド**：`lerobot-teleoperate`・`lerobot-record` は、止めると**フォロワーの力が抜けて腕が倒れる**。先にリーダーで低い姿勢に下ろすか、フォロワーを支えながら止める。`lerobot-rollout` は、止めても**つないだときの姿勢へ 3 秒で自分で戻る**（Ctrl+C では止まらない）。動いている間と戻る間は手を出さず、腕から 1m 離れて 5V の線に手が届く所にいる（[データ収集と学習の手順書](../データ収集と学習の手順書.md) の 14-1）。
- 本家のコマンドでフォロワーを使う前は、**毎回、直前に** `tools\prime_goal.py <フォロワーのポート>` を流し、`OK` を確かめる。流した後はフォロワーを動かさず、5V も抜かずに、すぐ本家のコマンドを始める（[P-001](../rules/RULES.md)）。
- 腕を動かすコマンドは、Claude が Terminal のタブで流し、利用者が Enter を押す。道具が自分で止まったら、同じコマンドをそのまま流し直さず、Claude に言う。

## §0. 毎回の始め：つなぐ・どの腕かを確かめる（5 分）

1. 使う腕の基板に、5V と USB を差す。
2. Claude に「つないだ」と言い、**どの腕（フォロワーかリーダーか）をつないだか**も言う。Claude はポートの一覧を出すが、ポートとシリアル番号で分かるのは**基板**だけで、腕は分からない（基板は 2 枚とも同じ物で、モーターの ID はモーターの側にある。[組み立て手順書](../組み立て手順書.md) STEP 2 の表の下）。腕は、目で見て答える（フォロワーは購入品の部品、リーダーは持ち手とトリガーの付いた刷った部品）。

| 基板（いつもの組） | いつもの番号 | USB シリアル番号 |
|---|---|---|
| フォロワーに付けた基板 | COM11 | 5AE7044447 |
| リーダーに付けた基板 | COM10 | 5AE7049321 |

3. Claude が `tools\scan_arm.py <ポート>` で 6 個のモーターの返事を確かめる（力は入れない。腕は動かない）。`ALL 6 OK` なら先へ。ただしこれも腕の区別にはならない（どちらの腕も同じ型のモーターで返事をする）。
4. いつもの組と違う（フォロワーの腕に 5AE7049321 の基板が付いている等）ときは、Claude がコマンドのポートを読み替える。フォロワーの較正 `follower1` と D1 の換算は、フォロワーの**腕**に付く物なので、腕を取り違えないことだけが大事。

- 2026-11-24 に、Claude がこの会話で COM10（シリアル 5AE7049321 の基板。表ではいつもリーダーの基板）だけを見つけ、`scan_arm.py COM10` で 6 個とも返事があった。2026-11-26 に利用者が「フォロワー」と答えた：**フォロワーの腕が 5AE7049321 の基板（COM10）でつながっていた**。基板を付け替えたのか、線だけ差し替えたのかは聞いていない。その組のままなら、D1 のコマンドの `COM11` は Claude が `COM10` に読み替える。

## §2. D1：換算の式と手元のカメラ（半日）

手順：[D1](D1_換算の式と手元のカメラ.md)。使う腕は**フォロワーだけ**。この §2 の中で腕が自分で動くのは、下の 3 の確かめ（±10°）だけ。この日は、フォロワーに力を入れる本家のコマンドを流さない。

1. §0 で、フォロワーの腕がつながっていることを確かめる（腕を目で見て答える）。
2. 電源の確かめ（1-1 と同じ）。
3. 手首の台を付ける（5V と USB を抜いてから。D1 の 2）→ 差し直して、Claude が `safe_wiggle.py` で確かめる。腕は、**肘を少し曲げ、机にも土台にも触れない空中の姿勢**で持つ（たたんで机に当てると、負荷で途中で止まる）。**Enter は 2 回**：1 回目の前は、支える手を軽く添えるだけにする（力が入って 1 秒ほどで、各関節が ±10° 動いて戻る）。2 回目は「SUPPORT THE ARM」と出たら、**腕を支えてから**。どこかが跳んだら止めて Claude に言う。
4. K1 の換算の式：`k1_calib.py`（D1 の 3）。力は抜いたまま、画面の指示どおりに手で腕を動かす（関節の向き 5 回 → 基準の姿勢 → 確かめの姿勢 → 爪）。**始める前に D1 の 3 の 2）基準の姿勢を読んでおく**。回さない関節は、もう一方の手で押さえる。
5. 手元の USB カメラ 2 台（D1 の 4）：番号を調べ、真下に向けて方眼の紙を撮り、レンズから紙までの高さを Claude に言う。**1 枚撮るたびに Claude に言う**（上書きされるため）。
6. 5 の結果で、Claude が買う物を絞る → 注文する（D1 の 5）。

D1 で残るもの：`sim\calib\k1_follower1.json`（`"verified": true`）、カメラの番号と型番、カメラごとの絵。

## §3. リーダーを組み、較正し、テレオペ（B の P0）

手順：[組み立て手順書](../組み立て手順書.md) の STEP 6〜8。

1. STEP 6：リーダーを組む。6-2 の表で、L1・L3 が C044、L2 が C001、L4〜L6 が C046 かを確かめる。
2. §0 で、リーダーの 6 個の返事を確かめる（STEP 6 の最後の欄）。
3. STEP 7：リーダーの較正。MIN が 0 付近で MAX が 4095 付近の関節があったら、保存せずにやり直す（[P-002](../rules/RULES.md)）。1〜3 は §2 と同じ日でもよい。
4. STEP 8：テレオペ（**D1 と別の日**）。順は次のとおり：
   1. 8-1 の確認：2 台ともクランプで机に留める。フォロワーのまわり 1m に物と人がいない。2 台とも電源と USB。
   2. `compare_pose.py` で、`<<<` の付いた関節のリーダーをフォロワーの姿勢に寄せ、全部消えたら Ctrl+C（どちらにも力は入らない）。
   3. **初回は安全版** `safe_teleop.py`（8-2 の 2）。「Support the FOLLOWER」と出たら、フォロワーを支え、リーダーは動かさずに Enter。「Caught up」と出てからリーダーを動かす。8-3 の表を見る。止めるときは Ctrl+C → 「SUPPORT THE FOLLOWER」でフォロワーを支えて Enter。
   4. 安全版で問題が無かったら、本家の `lerobot-teleoperate` を試す：`compare_pose.py` → `prime_goal.py`（フォロワーのポート）で `OK` → フォロワーを動かさず 5V も抜かずに、すぐ始める。止める前に、リーダーでフォロワーを低い姿勢に下ろす（止めると腕が倒れる）。
   5. 8-3 の表に全部チェックが付けば P0 は終わり。

- 本家の `lerobot-teleoperate` を `prime_goal.py` の後に流すのは初めて（[計画書_テレオペ以降](../plan/計画書_テレオペ以降.md) の前提 1）。始まりの瞬間は腕から離れ、5V の線に手が届く所にいる。
- テレオペの間に、赤い立方体をつかんで箱に入れられるかを試し、立方体の大きさを決める（1-7）。
