2. D4 の最後の回の記録と、直した版の差（何を直したか）を Claude が書く。

## 2. 1 回目は空中で（+40mm）

組が D4 と違う、または道具を直した後は、最初の 1 回を D4 の 2 と同じに空中で流す（`--air 40`）。組によって +40mm が届かないときは、**流さない**（`puzzle_run.py` は実機で 40mm 未満を断る。決まりを変えるかは利用者が決め、道具は隣の会話が直す）。止まらずに終わってから 3 へ。

## 3. 机の高さで 5 回

1. ピースを、Claude が言う置き場に置く（毎回置き場を変える。Claude が置き場の表を前もって作り、順を決めておく。結果を見てから置き場を変えない）。
2. 腕を写す姿勢に持ち、Claude がタブで流す。D4 の 2 の 4〜5 と同じに見守る。
3. 1 回ごとに、Claude が上のカメラの絵で、完成したか・どのピースがどれだけずれたかを読む。利用者は、完成した形の外の辺を鋼の定規で 1 か所測って言う。
4. 失敗した回は、何個目のどの段で何が起きたかを Claude が書く。
