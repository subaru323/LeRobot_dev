LeRobot システムマップhuggingface/lerobot · README と公式文書に基づく · 調査日 2026-10-15

LeRobot は、実ロボットの「操作・記録・学習・配備」を 1 つの流れで扱う Hugging Face の PyTorch ライブラリです。ロボットや操作器の種類を隠す抽象層（Robot / Teleoperator）、データの形の違いを埋める Processor、標準のデータ形式 LeRobotDataset、方策（Policy）、そして Hub が、互いにどうデータを受け渡すかを、分子の動きとして示します。ソースコード本体は未読で、公式文書と第三者の解析記事から組んだ図です（各箱のタグと、右の「注意点・未確認事項」を参照）。

関連ページ：LeRobot 詳細マップ ・ SO-101 シミュレータ（そこから「手で動かす」へ）

図の見方
  • 流れを追う：下の「実機の一生」から 1 つ選ぶと、その流れの全手順が番号つきの矢印で図に出ます。「次へ」か ← → キーで 1 手順ずつ進みます。図の下に、同じ番号で手順の一覧が並びます。
  • 線の描き分け：太線がいまの手順、細い実線が済んだ手順、点線がこの後の手順。矢印がデータの向きです。
  • 箱の右上のタグ：緑の「一次情報」は README・公式文書で確認した内容、橙の「二次情報」は第三者の解析記事のみ、橙の「推定」は断片的な記述からの推測です。
  • 赤枠と「!」：未確認・要注意の項目がある箱（右の「注意点・未確認事項」と対応）。フローを選んでいる間は隠します。
  • 分子にカーソルを合わせると中身の例、箱をクリックするとその箱に出入りするデータの一覧が出ます。

    手順の流れ番号は図の番号と同じ · クリックでその手順へ · ← → キーでも進めます
