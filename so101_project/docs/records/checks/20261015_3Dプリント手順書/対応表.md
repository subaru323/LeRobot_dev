# R-001 点検への対応（3Dプリント手順書 2026-10-15）

点検の出力: [review.md](review.md)。手順書: [3Dプリント手順書.md](../../../3Dプリント手順書.md)。精査前の版: [バックアップ](../../backup/3Dプリント手順書_20261015_精査前.md)。

| 番号 | 要旨 | 対応 | 理由・確かめたこと |
|---|---|---|---|
| 1 | 実部品1個の確認では代表にならない。輪郭補正を全体に掛けると外形も変わる | 一部 | 外形も細くなることを強く書いた。プレート1（モーターがはまる部品が多い）を先に刷って確かめる案を 5-2 に足した。部品ごとに補正を掛ける方法は、画面の項目名を確かめられないので入れなかった |
| 2 | 穴補正は片側の量。判定基準があいまい。値を変えたら確かめずに本番へ進む | 受け入れ | 公式Wiki「0.5mm小さい穴には +0.25mm」で片側の量だと確認。表に書いた。判定を「お手本動画と同じくらい」に合わせ、値を変えたらゲージを刷り直すことにした |
| 3 | 大きいモデルを読み込むと縮小を聞かれ、「はい」で縮む | 受け入れ | 確認の画面が出るかは確かめていないが、縮むと全部が無駄になるので注意を足した |
| 4 | かたまりごとに移す操作が書かれていない | 受け入れ | 点検役の案（プレートごとに読み込み、使わない部品を消す）に変えた |
| 5 | プレート1の余白が小さい | 受け入れ | 余白が片側5mmほどであることと、枠外の警告で確かめることを書いた。170×147mm は STL の測定値 |
| 6 | 作業の順番とプリセットの保存の食い違い | 受け入れ | 実部品の確認を STEP 3-3 に移した。フィラメントのプリセットの保存と、輪郭補正を変えたときの上書き保存を足した |
| 7 | 根拠の無い言い切り | 受け入れ | 壁ループ数は「この手順書の判断」、充填密度としきい値角度は README を出典に、1層目の話は「経験則」とした |
| 8 | 日本語の画面名を確かめていない | 受け入れ | 「この版について」に、確かめていないことと英語名で探すことを書いた |
| 追1 | プレートごとに読み込む作り方 | 受け入れ | 4 と同じ |
| 追2 | ノギスで測る | 受け入れ | 任意の手順として足した |
| 追3 | 先に1枚刷って確かめる | 受け入れ | 5-2 に足した |

機械検査（doc_lint）は「拡大率 100%」を手書きの割合の疑いとして拾ったが、画面の設定値なので空振り。
