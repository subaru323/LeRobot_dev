### 1. 2-6 の実部品での確認が、本番の部品を代表していない（最も重い）

- **どこ**：2-6 の「Motor_holder_SO101_Base を1個だけ…刷ります」と、表の「きつい → X-Y輪郭補正を -0.05mm」。
- **何が問題か**：
  - 文書自身が、本番の部品ではモーターがはまる面の多くに X-Y穴補正が効かないと書いています。そうなると、STEP 2 のゲージで決めた値は本番の部品にほぼ当てはまりません。それなのに、確かめるのは1部品だけです。
  - Wrist_Roll_Pitch は閉じた穴として現れた唯一の部品なので、穴補正の効き方が他と違います。それでも確認の対象に入っていません。
  - 一部の層だけ穴が閉じる部品では、補正が効く層と効かない層ができ、穴の中に段差が出るおそれがあります。この点に触れていません。
  - 輪郭補正をプロセス全体で -0.05mm にすると、12部品すべての外形が細くなります。部品どうしがはまる所や、ネジのボス（ネジを受ける出っ張り）の肉厚も変わります。「外形も少し小さくなります」の一言では軽すぎます。
- **どう直すか**：
  - 確認する部品に Wrist_Roll_Pitch を足します。
  - 輪郭補正は全体には掛けず、モーターがはまる部品だけに個別に設定します（オブジェクト一覧で部品を右クリックして、プロセスの設定を足す）。
  - 補正後は、他の部品と組み合わせて確かめる手順も入れます。
- **確かさ**：理屈の上では高い。ただし、実際にどれだけ影響が出るかは試し刷りが無いので分かりません。

### 2. 2-5 の補正値の刻み方と判定基準があいまい。逆の読み方もできる

- **どこ**：2-2 の「0.1mm狭い」、2-3、2-5。
- **何が問題か**：
  - Bambu Studio の X-Y穴補正は、穴の輪郭を外側へずらす量です（穴の各辺がこの値だけ外へ動きます）。+0.075mm なら、穴の幅は約0.15mm 広がります。ゲージ2種の穴の差は合計0.1mm しかないので、+0.075mm では効きすぎるおそれがあります。
  - 逆の読み方もできます。補正0で Gauge_0 が「きついが入る」状態は、公式の意図する「しっかりはまる（snug）」である可能性があります。2-5 の合格基準「スッと入り、ガタつかない」は README の言い方と照合されていません。
  - 「+0.10mm に変えて本番へ（試し刷りはもうしなくてよい）」とあり、値を変えたあと確かめずに本番の数時間のプリントへ進みます。
- **どう直すか**：
  - 補正値が片側の量であることを書きます。
  - 合格基準を、README とお手本動画の言い方に合わせます。
  - 値を変えたら、ゲージをもう1個刷ってから本番へ進むようにします。ゲージは小さいので、手間はわずかです。
- **確かさ**：補正値が片側の量だという点は中〜高。どの状態を合格とするかは中。

### 3. 3-1 で、大きすぎるモデルを読み込んだときの縮小の確認に答えてしまう

- **どこ**：3-1 の2「全体は約38cm角で、プレートからはみ出しますが問題ありません」。
- **何が問題か**：プレートより大きいモデルを読み込むと、Bambu Studio が「プレートに合わせて縮小しますか」と聞くことがあります（PrusaSlicer 由来の確認）。初心者が「はい」を押すと、部品が縮んだまま刷られ、モーターが入りません。
- **どう直すか**：「縮小するか聞かれたら『いいえ』」と明記します。読み込んだ後に、拡大率が 100% のままであることを確かめる手順も足します。
- **確かさ**：中（この確認が出るかどうかは版によります）。

### 4. 3-3 の「かたまりごと移す」操作の説明が無い（初心者が一番詰まる所）

- **どこ**：3-3 の1〜3。
- **何が問題か**：
  - 分割した後、5個のかたまりをまとめて選ぶ方法がありません。番号だけの名前では、一覧から選ぶのも難しい所です。並びを崩さずに別のプレートへドラッグする方法も書かれていません。
  - プレートを足すと、どの位置に並ぶのかも書かれていません。
  - プレートの枠から少しでもはみ出した部品は、そのプレートに入りません。この注意もありません。
- **どう直すか**：選び方と移し方を具体的に書きます（例：3D表示で範囲を囲んで選ぶ）。もっと確実な代わりの手順は、末尾の「追加の打ち手」の1つ目に書きました。
- **確かさ**：高い（手順が抜けていることは文書から確か）。

### 5. プレート1（170×147mm）の余白が小さい

- **どこ**：3-3 の表。
- **何が問題か**：A1 mini のプレートは 180mm 角なので、余白は片側5mm です。ブリム（部品の周りに付けるつば）が自動で付くと、はみ出すことがあります。中央へ手で移すときに少しずれただけでも、はみ出します。文書は「収まる」と言い切っており、言い過ぎです。
- **どう直すか**：
  - ブリムを「なし」にするか、プレート1だけブリムの有無を確かめる手順を足します。
  - STEP 4 の「はみ出していない」の確認は、Bambu Studio が出す枠外の警告で確かめると明記します。
- **確かさ**：中。

### 6. 作業の順番と、プリセットの保存に食い違いがある

- **どこ**：作業の流れの表、2-6 の1、2-5 の「上書き保存」、1-2。
- **何が問題か**：
  - 表では STEP 2 が終わってから STEP 3 へ進みますが、2-6 では STEP 3-1 を先に行います。
  - 2-6 で刷ったプロジェクトを保存して 3-3 で使い続けるのかが書かれていません。
  - 輪郭補正を変えたときに、プリセットへ上書き保存する指示がありません。2-7 に記入するだけです。
  - 1-2 でノズル温度やベッド温度を変えても、フィラメントのプリセットを保存する手順がありません。次に開いたとき元に戻ります。
- **どう直すか**：
  - 2-6 の前に「3-1 を行い、プロジェクトを保存する」と入れます。
  - 輪郭補正を変えたら、プリセットに上書き保存すると書きます。
  - フィラメントのプリセットも「SO101用」として保存する手順を足します。
- **確かさ**：高い。

### 7. 根拠が書かれていない言い切り

- **どこ**：
  - 1-3「壁ループ数 3：Fast PLAの割れ対策」
  - 5-2「1層目が成功すれば、その後もほぼ失敗しません」
  - 1-2 のプロファイルを Generic PLA High Speed にする理由
  - サポートのしきい値 45° と README の対応
- **何が問題か**：照合した資料（README、Wiki、販売ページ）のどれから出た話かが分かりません。特に「割れ対策」は、Fast PLA が割れやすいことを示す根拠がありません。
- **どう直すか**：根拠のあるもの（README の印刷設定など）は出典を書きます。根拠の無いものは「経験則」「推奨」と弱めます。
- **確かさ**：中。

### 8. 日本語の画面での項目名が、確かめられていない

- **どこ**：STEP 1 と STEP 4 の日本語の名前（「詳細」「X-Y穴補正」「すべてのプレートをスライス」「サポートペイント」「ブロック」など）。
- **何が問題か**：英語名（X-Y hole compensation、Slice all、Export plate sliced file、Split → To objects、Threshold angle の初期値30° など）は、私の知る限り正しいです。一方、日本語の画面の訳語は版によって違います。この文書も照合した資料に入れていません。
- **どう直すか**：手元の Bambu Studio の版を書き、実際の画面で名前を確かめます。確かめられない所は「英語名で探す」と案内します。
- **確かさ**：低〜中（誤りがあると断定はできません。確かめていない、という指摘です）。

### この文書に足すべき追加の打ち手

1. **かたまりを移さずに済む作り方**：プレートごとにまとめファイルを読み込んで分割し、そのプレートで使わない部品を消します。これを3枚分くり返します。ドラッグしないので、並びを崩したりプレートからはみ出させたりする失敗がなくなります。
2. **穴をノギスで測る**：ゲージの穴と実部品のモーター穴の幅をノギスで測り、STL の値（34.9×24.7mm）と比べて記録します。「きつい」「ゆるい」という手の感覚だけに頼らずに済み、補正値を決める根拠になります。
3. **プリントの順番を工夫する**：最初のプレートには、モーターがはまる部品が多い方を選びます。1枚目が終わったら、組み立て担当と一緒にモーターと仮に組んでみます。そのうえで残りの2枚を始めれば、手戻りが1枚分で済みます。
