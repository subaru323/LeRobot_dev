- 対象：SO-ARM101 リーダーアーム 1台分（12部品）

## STEP 1　Bambu Studioの設定

画面左上に、「プリンター」「フィラメント」「プロセス」の3項目が並んでいます。
（表示が英語の場合に備えて、英語名を（ ）で添えています）

### 1-1. プリンター（Printer）

| 項目 | 設定 |
|---|---|
| プリンター | Bambu Lab A1 mini 0.4 nozzle |
| プレートタイプ | 実機と同じもの（A1 miniの標準は Textured PEI Plate） |

### 1-2. フィラメント（Filament）

| 項目 | 設定 |
|---|---|
| プロファイル | Generic PLA High Speed（一覧になければ「フィラメントを選択/追加」から追加） |
| ノズル温度 | 210〜220℃（メーカーの推奨範囲は190〜230℃） |
| ベッド温度 | 55〜60℃ |

### 1-3. プロセス（Process）

1. プリセットで **0.20mm Standard @BBL A1M** を選びます。
2. 右上の「**詳細**」（Advanced）スイッチをオンにします。
3. 次の表のとおり設定します。

| タブ | 項目 | 値 | 備考 |
|---|---|---|---|
| 品質（Quality） | 積層ピッチ（Layer height） | 0.2mm | プリセットで設定済み |
| 品質（Quality） | X-Y穴補正（X-Y hole compensation） | **+0.075mm（仮）** | STEP 2の結果で確定させる |
| 強度（Strength） | 壁ループ数（Wall loops） | 3 | Fast PLAの割れ対策 |
| 強度（Strength） | 充填密度（Sparse infill density） | 15% | |
| サポート（Support） | サポートを有効化（Enable support） | オン | |
| サポート（Support） | タイプ（Type） | 標準（自動） / normal(auto) | |
| サポート（Support） | しきい値角度（Threshold angle） | 45° | 初期値は30° |

4. プリセット名の横にある保存アイコンを押して、「**SO101用**」という名前で保存します。

## STEP 2　ゲージの試し刷り（穴の寸法合わせ）

### 2-1. 目的

本番の部品には、STS3215モーターをはめる穴があります。この穴が、きつすぎずゆるすぎない大きさに仕上がるよう、先に小さなゲージで確認します。

### 2-2. ゲージの種類

| ファイル | 寸法 | 役割 |
|---|---|---|
| `Gauge_0.STL` | 本番の部品と同じ | **判定に使う** |
| `Gauge_tight_1.STL` | 0より0.1mm狭い | 比較用。プリンターのずれがどちらの方向かを見る（もう刷らなくてよい） |

### 2-3. これまでの記録

| 回 | 刷ったもの | X-Y穴補正 | 結果 | 判断 |
|---|---|---|---|---|
| 1回目 | Gauge_0 | 0 | きつすぎるが入る | 穴が小さめに出来る |
| 1回目 | Gauge_tight_1 | 0 | 入らない | 同上 |
| 2回目 | Gauge_0 | +0.075mm | （記入） | （記入） |

### 2-4. 2回目の試し刷り手順

1. プレートに `Gauge_0.STL` を1個だけ置きます。**向きは変えません。**
2. プロセス設定が「SO101用」（X-Y穴補正 +0.075mm）になっていることを確認します。
3. スライスしてプリントします。
4. STS3215モーターをはめて、お手本動画（ https://youtu.be/dss8E3DG2rA ）と比べます。
5. **モーターを力ずくで押し込まないこと。** ゲージが割れたり、モーターに傷が付いたりします。

### 2-5. 判定

| 結果 | 対応 |
|---|---|
| 手で押し込むとスッと入り、ガタつかない | **合格**。+0.075mmで確定し、STEP 3へ |
| まだ少しきつい | +0.10mmに変えて本番へ進む（試し刷りはもうしなくてよい） |
| ガタつく | +0.05mmに変えて本番へ進む |
| 1回目とはまり具合がまったく変わらない | 補正が効いていない。X-Y穴補正を0に戻し、「X-Y輪郭補正」（X-Y contour compensation）を -0.05mm にして、もう1個刷る |

値を変えたら、「SO101用」プリセットに**上書き保存**します。

### 2-6. 確定値

| 項目 | 確定した値 |
|---|---|
| X-Y穴補正 | ______ mm |
| X-Y輪郭補正（使った場合） | ______ mm |

## STEP 3　本番データの準備

### 3-1. 読み込みと分割

1. Bambu Studioで新しいプロジェクトを作り、プロセスに「SO101用」を選びます。
2. `Prusa_Leader_SO101.stl` をプレートにドラッグします。（プレートからはみ出しますが問題ありません）
3. モデルを右クリックし、「**分割**」→「**オブジェクトに分割**」（Split → To objects）を選びます。
4. 左のオブジェクト一覧に部品が並びます。**部品の向きは変えないでください。** 最初からプリントしやすい向きになっています。

うまく分割できない場合は、部品ごとのファイル（ https://github.com/TheRobotStudio/SO-ARM100/tree/main/STL/SO101/Individual ）から、次の12個を1つずつダウンロードして読み込みます。

### 3-2. 部品が12個そろっているか確認

| 区分 | 部品名（ファイル名） | 確認 |
|---|---|---|
| 共通 | Base_SO101 | [ ] |
| 共通 | Base_motor_holder_SO101 | [ ] |
| 共通 | Motor_holder_SO101_Base | [ ] |
| 共通 | Motor_holder_SO101_Wrist | [ ] |
| 共通 | Upper_arm_SO101 | [ ] |
| 共通 | Under_arm_SO101 | [ ] |
| 共通 | Rotation_Pitch_SO101 | [ ] |
| 共通 | Wrist_Roll_Pitch_SO101 | [ ] |
| 共通 | WaveShare_Mounting_Plate_SO101 | [ ] |
| リーダー専用 | Handle_SO101 | [ ] |
| リーダー専用 | Trigger_SO101 | [ ] |
| リーダー専用 | Wrist_Roll_SO101 | [ ] |

分割すると、細かい破片が余分にできることがあります。12個より多い場合は、部品の一部でないことを確認してから削除してください。

### 3-3. 2台分のプレートに振り分ける

1. プレートを追加して、プレート1とプレート2の2枚にします。
2. 次の表を目安に部品を振り分けます。

| プレート | 載せる部品（目安） | 使うプリンター |
|---|---|---|
| プレート1 | Base、Upper_arm、Motor_holder_Base、Rotation_Pitch、WaveShare_Mounting_Plate、Trigger | A1 mini 1号機 |
| プレート2 | Under_arm、Base_motor_holder、Motor_holder_Wrist、Wrist_Roll_Pitch、Handle、Wrist_Roll | A1 mini 2号機 |

3. 各プレートで「**配置**」（Arrange、キーボードの `A`）を押して、間隔を整えます。
4. 入りきらない部品があれば、3枚目のプレートに回します。
5. スライス後に表示されるプリント時間を見て、**2枚の時間がだいたい同じになるように**部品を入れ替えます。

## STEP 5　プリント

### 5-1. プリンターに送る

**方法A：Wi-Fiで送る**
1. 右上の「**プリント**」（Print plate）を押します。
2. 送信先のA1 miniを選びます。プレート1は1号機、プレート2は2号機です。
3. 「ベッドレベリング」はオンのまま、「送信」を押します。

**方法B：microSDで渡す**
1. 「プリント」ボタン横の ▼ →「**エクスポート**」（Export plate sliced file）を選びます。
2. `.gcode.3mf` ファイルをmicroSDに保存します。
3. A1 miniにmicroSDを挿し、本体の画面でファイルを選んで開始します。

### 5-2. プリント中の注意

- **1層目がきれいにプレートへ貼り付くまで見届けます。** 1層目が成功すれば、その後もほぼ失敗しません。
- 途中で、部品がプレートから剥がれていないか、ときどき様子を見ます。

### 5-3. よくある失敗と対処

| 症状 | 対処 |
|---|---|
| 1層目がプレートに付かない | プレートを洗い直す。指で触った跡（皮脂）が原因のことが多い |
| 途中で部品が剥がれた | その部品だけを新しいプレートに移して、刷り直す |
| 細い糸を引いたような線が多い | 見た目だけの問題なので、後でカッターで取る。多すぎる場合はフィラメントが湿気を吸っている可能性がある |

| プレート | 開始日時 | 終了日時 | 結果 |
|---|---|---|---|
| プレート1（1号機） | | | |
| プレート2（2号機） | | | |

## STEP 6　後処理と検品

### 6-1. 取り外し

1. プレートが**冷めてから**外します。
2. プレートを軽く曲げると、部品が剥がれます。

### 6-2. サポート除去

1. 小さなマイナスドライバーを、サポートの下に差し込んで剥がします。
2. **Triggerは細くて折れやすい**ので、力を入れすぎないようにします。
3. ネジ穴とモーターを入れる穴の中に、サポートやバリ（はみ出したカス）が残っていないか確認します。

### 6-3. 検品

| 確認項目 | 確認 |
|---|---|
| 12個すべてそろっている（STEP 3-2の表で再確認） | [ ] |
| ネジ穴にサポートやバリが残っていない | [ ] |
| モーターを入れる穴に、STS3215が入る | [ ] |
| 割れや、層の剥がれがない | [ ] |
| 反り（平らな面が浮いている）がない | [ ] |

不良があった部品は、その部品だけを刷り直します。

## STEP 7　組み立て担当へ渡す

1. 部品を袋に入れて渡します。**TriggerとHandleは別の袋**にしておくと、破損を防げます。
2. 次の内容を口頭で伝えます。

| 伝えること |
|---|
| 使ったフィラメント：Ender Fast PLA（PLA+より少し割れやすいので、ネジを締めすぎないように） |
| X-Y穴補正：確定値 ______ mm で刷った |
| ネジ穴がきついときは、M3ネジを1回ねじ込んでから抜くと、ネジ山が付いて組み立てやすくなる |
| モーターの穴がきついときは、無理に押し込まず、ヤスリで少し削る |

## 保管とメモ

- 使わないフィラメントは、乾燥剤と一緒に袋に入れて保管します。湿気を吸うと、糸引きや割れの原因になります。
- 「SO101用」プリセットは、フォロワー部品を刷り直すときにも使えます。フォロワー用のまとめファイルは `STL/SO101/Follower/Prusa_Follower_SO101.stl` です。
