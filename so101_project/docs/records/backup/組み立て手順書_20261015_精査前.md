# SO-ARM101 組み立て手順書（Windows + uv）

- 対象：SO-ARM101 Standard版（電源はすべて5V）
- 構成：フォロワー＝購入したプリント済み部品、リーダー＝自分でプリントした部品
- ゴール：リーダーを手で動かすと、フォロワーが同じ動きをする（テレオペ）
- 3Dプリントの手順はこの手順書には含めていません

## STEP 1　ソフトのインストール

### 1-1. Git

https://git-scm.com/downloads/win からダウンロードし、インストーラーは全部初期設定のまま進めます。

### 1-2. uv

PowerShellで次を実行します。

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

参考：https://docs.astral.sh/uv/getting-started/installation/

インストールが終わったら、**PowerShellを一度閉じて開き直して**ください。

### 1-3. LeRobot

```powershell
cd ~
git clone https://github.com/huggingface/lerobot.git
cd lerobot
uv venv --python 3.12
.venv\Scripts\activate
uv pip install -e ".[feetech,core_scripts]"
```

- Python 3.12 は uv が自動でダウンロードします。
- `activate` で「スクリプトの実行が無効」と出たら、次を1回実行してから、もう一度 `activate` します。
  ```powershell
  Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  ```

### 1-4. 次回以降の作業開始時

作業を始めるときは、毎回この2行を実行します。

```powershell
cd ~\lerobot
.venv\Scripts\activate
```

行頭に `(lerobot)` のような表示が出ていれば準備完了です。

- [ ] STEP 1 完了

## STEP 2　ポートの確認

1. 基板1枚に、**5V電源とUSBの両方**をつなぎます（USBだけでは給電されません）。
2. 次を実行し、指示が出たらUSBを抜いてEnterを押します。
   ```powershell
   lerobot-find-port
   ```
3. 表示された番号（例：`COM3`）を、テープで基板に書いておきます。
4. もう1枚の基板でも同じことをします。

| 基板 | COM番号 |
|---|---|
| フォロワー用 | COM____ |
| リーダー用 | COM____ |

※ この手順書では、フォロワー＝`COM3`、リーダー＝`COM4` として書いています。自分の番号に読み替えてください。

### COMポートが出てこない場合

- デバイスマネージャーを開き、「ポート（COMとLPT）」を確認します。
- 表示されなければ、CH343ドライバを入れます。
  WCH公式：https://www.wch-ic.com/downloads/CH343SER_EXE.html
- 基板のジャンパー2個が「B」側（USB）になっているか確認します。

- [ ] STEP 2 完了

## STEP 3　モーターにIDを書き込む（組み立て前）

**最初に動画を1回見てから作業してください。**
https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/setup_motors_so101_2.mp4

### 3-1. フォロワー

```powershell
lerobot-setup-motors --robot.type=so101_follower --robot.port=COM3
```

### 3-2. リーダー

```powershell
lerobot-setup-motors --teleop.type=so101_leader --teleop.port=COM4
```

### 3-3. やり方（両方共通）

1. 「Connect the controller board to the 'gripper' motor only」と表示されます。
2. **そのモーター1個だけ**を、3ピンケーブルで基板につなぎます。ほかのモーターとはつながないでください。
3. Enterを押すと、IDが書き込まれます。
4. 書き込んだモーターに、テープで番号（F6、L6など）を書きます。
5. 次のモーターに付け替えて、同じことを繰り返します。

| 順 | 関節 | ID | フォロワー | リーダー |
|---|---|---|---|---|
| 1 | gripper | 6 | [ ] F6 | [ ] L6（C046） |
| 2 | wrist_roll | 5 | [ ] F5 | [ ] L5（C046） |
| 3 | wrist_flex | 4 | [ ] F4 | [ ] L4（C046） |
| 4 | elbow_flex | 3 | [ ] F3 | [ ] L3（C044） |
| 5 | shoulder_lift | 2 | [ ] F2 | [ ] L2（C001） |
| 6 | shoulder_pan | 1 | [ ] F1 | [ ] L1（C044） |

### 3-4. 注意

- リーダーは、**型番シールを見て表のとおりのモーターをつなぐ**こと。ギア比を間違えると、リーダーが重くなったり、自重で垂れたりします。
- エラーが出たら、電源、USB、3ピンケーブルの3つが抜けていないか順に確認します。作業中に電源ケーブルが抜けやすいので注意してください。

## STEP 4　フォロワーの組み立て（購入品の部品）

### 4-1. ネジの使い分け

| ネジ | 使う場所 |
|---|---|
| M2×6mm（一番小さいネジ） | モーター本体を部品に固定する |
| M3×6mm | ホーン（上側）の固定、アーム部品どうしの固定 |

### 4-2. 共通のルール

- ホーンは各関節で上下2枚付けます。**ネジで留めるのは上側だけ**で、下側はネジ不要です。
- 手首（関節5）だけは、ホーンが1枚です。
- モーターを部品にはめたら、組み進める前に**3ピンケーブルを挿しておきます**。組んだ後だと挿しにくくなります。
- **F1〜F6のテープを見て、正しい関節に入れているか**確認しながら進めます。

### 4-3. 工程と動画

| 工程 | 内容 | 動画 | 確認 |
|---|---|---|---|
| 関節1 | 土台にF1を入れ、M2で4本固定（上2本・下2本）→ 肩の部品をM3で上4本・下4本 | https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint1_v2.mp4 | [ ] |
| 関節2 | F2を上から差し込み、M2で4本固定 → 上腕をM3で左右4本ずつ | https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint2_v2.mp4 | [ ] |
| 関節3 | F3をM2で4本固定 → 前腕をM3で左右4本ずつ | https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint3_v2.mp4 | [ ] |
| 関節4 | モーターホルダー4を通し、F4を入れてM2で4本固定 | https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint4_v2.mp4 | [ ] |
| 関節5 | F5を手首ホルダーに入れ、M2で前から2本固定 → ホーン1枚をM3で固定 → 手首をF4にM3で左右4本ずつ | https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Joint5_v2.mp4 | [ ] |
| グリッパー | グリッパーを手首ホーンにM3で4本 → F6をM2で左右2本ずつ → ホーン上下 → 爪をM3で左右4本ずつ | https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/Gripper_v2.mp4 | [ ] |

全体の流れを動画で見たいときは、Seeedの組み立て動画（YouTube）を参照してください。

## STEP 5　フォロワーのキャリブレーション

動画：https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/lerobot/calibrate_so101_2.mp4

```powershell
lerobot-calibrate --robot.type=so101_follower --robot.port=COM3 --robot.id=follower1
```

1. アームをクランプで机に固定します。
2. 電源とUSBをつなぎます。
3. コマンドを実行します。
4. 全関節を、可動範囲の**真ん中あたり**に手で合わせてからEnterを押します。
5. 各関節を、**端から端まで**ゆっくり動かします。
6. 終わったらEnterを押します。

**注意**：`--robot.id=follower1` の名前は、今後もずっと同じものを使ってください。キャリブレーション結果がこの名前で保存されます。

## STEP 8　テレオペで動作確認（ゴール）

動画（Seeed）：https://www.youtube.com/watch?v=hnRwfcyX1ZI

### 8-1. 実行前の安全確認

- [ ] 2台ともクランプで机に固定している
- [ ] フォロワーの周囲1m以内に、物と人がいない
- [ ] 2台とも電源とUSBがつながっている

### 8-2. 実行

```powershell
lerobot-teleoperate --robot.type=so101_follower --robot.port=COM3 --robot.id=follower1 --teleop.type=so101_leader --teleop.port=COM4 --teleop.id=leader1
```

### 8-3. 確認

| 確認項目 | 確認 |
|---|---|
| リーダーの肩を回すと、フォロワーの肩も同じ向きに回る | [ ] |
| 肩上げ、肘、手首曲げ、手首回転も同じように追従する | [ ] |
| トリガーを引くと、グリッパーが閉じる | [ ] |
| 異音、振動、急な動きがない | [ ] |

止めるときは `Ctrl + C` を押します。
異常な動きや異音があったら、**すぐ電源を抜いてください**。

## 困ったとき

| 症状・エラー | 対処 |
|---|---|
| `lerobot-...` が見つからないと言われる | STEP 1-4 の2行（`cd ~\lerobot`、`.venv\Scripts\activate`）を実行したか確認する |
| COMポートが出てこない | STEP 2 の「COMポートが出てこない場合」を参照 |
| `Could not connect on port` | COM番号が合っているか確認する。ほかのソフト（Arduino IDEなど）がポートを使っていたら閉じる |
| `Motor 'gripper' was not found` | 電源、USB、3ピンケーブルの抜けを確認する。電源は5Vアダプタか確認する |
| `Failed to sync read 'Present_Position'` | 電源が入っているか、3ピンケーブルが緩んでいないか確認する。LEDが消えているモーターがあれば、その手前のケーブルを疑う |
| `Magnitude ... exceeds 2047` | 電源を入れ直してキャリブレーションをやり直す。直らなければSeeedのサーボ調整ツールを使う（ https://wiki.seeedstudio.com/lerobot_steering_gear_debugging_tool ） |
| フォロワーの動きがリーダーとずれる | キャリブレーションをやり直す（下を参照） |
| キャリブレーションをやり直したい | `C:\Users\（ユーザー名）\.cache\huggingface\lerobot\calibration` の中身を削除してから再実行する。またはコマンド実行時に `c` を入力してEnter |
| それでも解決しない | LeRobot Discord（英語）： https://discord.gg/q8Dzzpym3f |
