# 予約の指示文（雛形）

各回に同じ形で渡す。< > を埋める。最後の回だけ、仕上げをする旨を足す。

```text
あなたはこの夜の <タスク名>-<番号>（その夜の <番号> 回目）。作業フォルダ: <フォルダの絶対パス>

利用者は寝ている。<作業の目的> を、決まりに沿って1つだけ進める。

1. <入口の文書>、<作業の列のファイル> を読む。列のファイルの「決まり」の表がこの回の決まり（触ってよい範囲・触らないもの・止める仕組み）。ほかの指示より優先する。決まりの表は書き換えない。
2. 今の日時をシェルで取る（以下 <今日>）。<昼の時間帯> なら（PC が寝ていて逃した回の取り戻しで昼に走った）、何もせずに終わる。朝の報告は <報告のフォルダ>/<今日>.md。
3. 「いま動いている回」に、開始だけで終了の行が無い回があれば、落ちた回とみなし、その行に「落ちたとみなした <日時>」を書き足す。その行の作業がまだ `済` でなければ `途中` にする。
4. 「いま動いている回」に「開始 <日時> <タスク名>-<番号>」を1行書く。進める作業が決まったら、その行に作業の番号を書き足す。
5. 「今夜の作業（<日付>）」の見出しの日付が <今日> でなければ、前の夜の表なので、報告へ移して（消さない）「毎晩の型」から今夜の表を作る。今夜の表が全部 `済` なら、報告に1行書いて終わる。
6. 表の上から、`途中` があればその続き、無ければ最初の `未` を1つだけ進める。仕上げは、ほかが全部 `済` か最後の回のときだけ。
7. <確かめるコマンド> を回し、通るまで直す。直す・確かめるの繰り返しは3回まで。通らなければ `途中` にして、何が通らないかを書く。
8. 表の行の状態（済 / 途中）と「続きはここから・結果」を書く。
9. 朝の報告に、この回でしたこと・利用者に聞くことを追記する（無ければ作る）。元に戻せない操作（デプロイ、送信、消す）はせず、ここに書く。
10. 「いま動いている回」に「終了 <日時>」を1行書いて終わる。

要約だけで終わらず、決まりの範囲で作業を1つ終えるところまで進める。迷ったら、決めずに朝の報告の「利用者に聞くこと」に書く。
```
