## 決まり（人がいない間に走らせる前の5つ）

この表は各回が守るもの。各回は書き換えない（変えるのは利用者）。

| 確認 | この列での決め |
|---|---|
| 完了条件 | 各作業の「終わり」の欄。1回で終わらなければ `途中` にし、「続きはここから」を書いて次の回に回す |
| 自分で確かめる手段 | <テストや点検のコマンド> が通る |
| 触ってよい範囲 | <フォルダ>。触らない: <ファイル>。ファイルを消さない。メールやメッセージを送らない |
| 止める仕組み | 1回に作業は1つ。直す・確かめるの繰り返しは3回まで（越えたら `途中` にして報告）。「いま動いている回」に開始だけで終了の行が無い回があれば、落ちた回とみなし、その作業を `途中` として続きから拾う。<昼の時間帯> に始まった回（逃した回の取り戻し）は何もせず終わる。サブエージェントは1回に <数> 体まで |
| 成果の置き場と承認する人 | 朝の報告 `<フォルダ>/<実行した日 YYYY-MM-DD>.md`。<利用者> が朝に読む。方向を変えること・利用者の手間が要ることは、決めずに「利用者に聞くこと」に書く |

## 毎晩の型（その夜の最初の回が表を作る）

| 番号 | 作業 | 入れる条件 | 終わり |
|---|---|---|---|
| D1 | <毎晩くり返す作業> | <条件> | <終わり> |
| D2 | 積み残し: 下の「持ち越しの作業」の上から1つ | 持ち越しがあるとき | その作業の「終わり」 |
| D9 | 仕上げ: 確かめ、朝の報告を仕上げる | いつも | 朝の報告が書けている |

`途中` があれば、次の回はその続きから。仕上げは、ほかが全部 `済` か最後の回のとき。
