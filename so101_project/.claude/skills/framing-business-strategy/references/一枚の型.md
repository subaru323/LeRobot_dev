# 提案の1枚の形と点検の問い

## 1枚の形

上の3つが考える型、下の3つが事業の大問い。各行の終わりに確からしさの札（【確】出どころあり・【一般】定番の型・【推】推測・【仮】置いた数）を付ける。

```
# <提案の名前>

1. 問い: <主語と比べる物が入った1文>
2. 結論: <仮説1文>
   - 理由1: <…>（本当なら見えるはず: <…>）
   - 理由2: <…>（本当なら見えるはず: <…>）
   - 理由3: <…>（本当なら見えるはず: <…>）
3. 大きさ: <式>
   | 数 | 弱気 | ふつう | 強気 | 出どころ |
   | … | … | … | … | <統計の名前 か 仮> |
   結果: 年 <…>〜<…>。一番効く数: <…>
4. 真似されない理由: <堀の型> — <なぜ相手が追いつくのに時間がかかるか>。打ち手のつながり: <…>
5. 技術が当たり前になった後に残る物: <つなぐ場所 / たまるデータ / 任せられる信頼 のどれを、どう押さえるか>
6. 顧客: 用事 <…>（代わりの手: <…>）
   | 役 | 誰 | 合格条件 |
   | 使う人 | … | … |
   | 決める人 | … | … |
   | 払う人 | … | … |
   | 止められる人 | … | … |
   今の客の段: <新しもの好き・先を見る人 / 慎重な多数派 / 保守派>、谷を越えたか: <同業の実績の有無>、最初の1業界: <…>

分かれる所: <論点> — 決め手 <…>。決め手を測る行動: <誰に何人・期間・やめる条件>
次に確かめること: <3つまで>
```

## 書き戻しの形（人の提案を分けるとき）

まず1文: この提案は「<…>」という問いへの答え。

| 6つ | 提案に書いてあること | 空き・弱い所 | 次に聞くこと |
|---|---|---|---|
| 問い | | | |
| 結論と理由 | | | |
| 大きさ | | | |
| 堀 | | | |
| 当たり前になった後 | | | |
| 顧客 | | | |

## 終える前の点検の問い

1. 問いは1文で、答えが出たら手が変わり、今の手持ちで答えが出せるか。
2. 結論が先にあり、理由が3つで重ならず、各理由に「本当なら見えるはず」が付いているか。
3. 大きさに式と各数の出どころか「仮」があり、3通りと一番効く数が出ているか。計算はコードで確かめたか。
4. 堀が型の名前で言えていて、「技術が優れている」だけになっていないか。
5. 当たり前になった後に残る物が、つなぐ・データ・信頼のどれかで具体的か。
6. 顧客の用事が製品名でなく用事で書かれ、使う人・決める人・払う人・止められる人の合格条件がそれぞれ書かれているか。
7. 出どころの無い数字を事実のように書いていないか。
8. 質問を返すだけで終えず、決め手を測る行動（誰に何人・期間・やめる条件）を1つ出したか。
