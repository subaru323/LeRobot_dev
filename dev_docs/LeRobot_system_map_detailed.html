SO-ARM101 の 3D プリント・配線から、モーター ID 設定・校正・遠隔操作・データ収集・学習・実機配備（同期 / RTC / リモート推論）・強化学習まで、データがどの箱をどう流れるかを、分子の動きで示します。前版は文書のみから組みましたが、本版はローカルの lerobot-main（version 0.6.2）のソースコードを読んで、クラス名・既定値・ファイルの行番号まで確認しました。Seeed Wiki の手順（ハード・3D プリント・電源）も統合し、本家との食い違いは右の「注意点」に並べています。

図の見方
  • 流れを追う：下の「実機の一生」から 1 つ選ぶと、その流れの全手順が番号つきの矢印で図に出ます。「次へ」か ← → キーで 1 手順ずつ進みます。図の下に、同じ番号で手順の一覧が並びます。
  • 線の描き分け：太線がいまの手順、細い実線が済んだ手順、点線がこの後の手順。矢印がデータの向きです。
  • 箱の右上のタグ：緑の「ソース確認」はコードを読んで確認、緑の「公式文書」はリポジトリ内 docs で確認、青の「Seeed Wiki」は Seeed の手順書のみ、橙の「推定」は推測です。箱を開くと、該当ファイルと行番号、コード片が出ます。
  • 赤枠と「!」：未確認・要注意の項目がある箱（右の「注意点・未確認事項」と対応）。フローを選んでいる間は隠します。
  • 分子にカーソルを合わせると中身の例、箱をクリックするとその箱に出入りするデータの一覧が出ます。

    手順の流れ番号は図の番号と同じ · クリックでその手順へ · ← → キーでも進めます
