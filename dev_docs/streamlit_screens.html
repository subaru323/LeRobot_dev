2. 腕の位置を合わせる

絵と同じ姿勢にしてから「できた」を押します。終わったら各関節をいっぱいまで動かします。

フォロワー：手順 1 / 2 腕を可動範囲の真ん中にしてください（図の姿勢）。
できた最初から

内部：lerobot-calibrate（Enter 入力を画面のボタンから送る）

3. お手本を見せる

リーダーアームを手で動かして、お手本を 30 回録画します。1 回 20 秒です。

● REC 00:12 / 00:20
録画済み12 / 30
この回を終える撮り直す録画をやめる
毎回、立方体を少しずつ違う場所に置いてください。同じ場所ばかりだと覚え方が偏ります。
内部：lerobot-record --dataset.num_episodes=30 --dataset.episode_time_s=20

4. 学習させる

お手本 30 回分で学習します。目安は数時間です。画面を閉じても学習は続きます。

step:12400 loss:0.071 lr:1.0e-05 ...（見本）
学習を止める
内部：lerobot-train --policy.type=act（HF Jobs など GPU 上で実行）

5. 動かしてみる

学習したモデルでロボットを動かします。終わるたびに、うまくいったかを押してください。

内部：lerobot-record --policy.path=…

数値と名前はすべて見本です。

Streamlit はボタンを押すたびにスクリプト全体を上から実行し直します。そのため長い処理（録画・学習）は必ず別プロセスで動かし、状態はファイルに書いて画面側から読みにいく形にします。こうしておけば、ブラウザを閉じたり再読み込みしたりしても処理は止まりません。

easy_lerobot/

├─ pages/

ページのファイルが班ごとに分かれているので、同じファイルを同時に触ることがほぼありません。

session_state に置くもの

キー中身
project開いている Project（中身は project.json）

session_state はブラウザのタブごとに消えます。消えて困るもの（どこまで進んだか）は必ず project.json にも書きます。

先に確かめておきたい落とし穴

キャリブレーションとポート検出は Enter 待ちで止まる

lerobot-calibrate と lerobot-find-port は内部で input() を呼びます。Runner が stdin をパイプでつなぎ、画面のボタンから改行を送る必要があります。

録画中の「次へ」「撮り直し」はキーボード操作

lerobot-record は Windows では pynput でキー（→ ← Esc）を拾います。画面のボタンから同じ操作をする方法は未検証です。1 回ずつ record を起動する、キー入力を送るなどの案を試す必要があります。

学習は手元 PC では回らない

CPU のみなので、学習ページは GPU 側にジョブを投げて進捗を受け取る作りになります。どこで回すかは未決です。

カメラの取り合い

画面のプレビューで開いたカメラは、録画を始める前に必ず閉じます。開いたままだと record 側で開けません。

叩き台です。画面の文言・数値はすべて仮のものです。
