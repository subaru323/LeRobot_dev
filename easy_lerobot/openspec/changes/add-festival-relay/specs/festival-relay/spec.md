# Spec Delta

## Purpose

来場者が自分のスマホのモバイル回線のまま、展示のミラーを操作できるようにする。そのための中継、ラズパイの Wi-Fi の扱い、命令と状態のやり取り、手首カメラの表示を定める。

## ADDED Requirements

### Requirement: VPS を通した来場者の操作
来場者は、ラズパイと同じ Wi-Fi に入らずに、VPS の HTTPS の URL を開いて操作できなければならない（SHALL）。ラズパイは外への接続だけを使い、インターネット側に待ち受けのポートを開けてはならない（MUST NOT）。VPS がラズパイへ渡す待ち受けは VPS の内側（127.0.0.1）だけとし、外から直接開けてはならない（MUST NOT）。

#### Scenario: モバイル回線から開く
- **WHEN** Wi-Fi を切ったスマホで VPS の URL を開く
- **THEN** 画面が表示され、ミラーの開始・停止が効く

#### Scenario: ラズパイの Wi-Fi を切り替える
- **WHEN** ラズパイを別の Wi-Fi（インターネットに出られるもの）につなぎ直す
- **THEN** 来場者の URL は変わらず、トンネルが張り直されたあとに同じ URL で操作できる

### Requirement: ラズパイ用の鍵の制限
VPS は、ラズパイ用の鍵で、決められた待ち受け（画面と ssh）以外の操作をさせてはならない（MUST NOT）。ラズパイ用の鍵でシェルにログインできてはならない（MUST NOT）。

#### Scenario: 鍵でログインしようとする
- **WHEN** ラズパイ用の鍵で VPS に ssh でログインしようとする
- **THEN** ログインできない

### Requirement: Wi-Fi は人が切り替える
ラズパイの Wi-Fi は、優先順位などで自動に切り替えてはならない（MUST NOT）。切り替えは人が行い、切り替え先でインターネットに出られないときは、一定時間のあとに元の Wi-Fi に戻らなければならない（SHALL）。

### Requirement: 手首カメラの表示
手首カメラの映像はネットで送らず、ラズパイにつないだディスプレイに表示しなければならない（SHALL）。
