# Spec Delta

## Purpose

アームの横に置いたラズパイで画面・接続・録画・デモを完結させ、ラズパイでは重すぎる学習だけを GPU のある PC に任せる。そのための役割分担、LAN からの利用方法、推論の実行場所の切り替えを定める。

## ADDED Requirements

### Requirement: ラズパイと GPU のある PC の役割分担
本番環境では、画面の提供、アームとカメラの接続、キャリブレーション、録画、デモの実行をラズパイ上で行わなければならない（SHALL）。学習（lerobot-train）はラズパイ上で実行してはならず（MUST NOT）、GPU のある PC で行う。データセットと学習済みモデルの受け渡しは Hugging Face Hub を通して行う（SHALL）。

#### Scenario: 録画したデータを学習に回す
- **WHEN** ラズパイで録画が正常に終わる
- **THEN** データセットは project.json の `dataset_repo_id` の名前で Hub に上がり、GPU のある PC はその名前で取得できる

#### Scenario: ラズパイで学習を始めようとする
- **WHEN** 本番環境の「学習させる」画面で開始を押す
- **THEN** ラズパイ上では lerobot-train を起動せず、GPU のある PC での学習を依頼する手順に進む

### Requirement: LAN からの利用
画面は、ラズパイと同じ LAN にある PC やタブレットのブラウザから、ラズパイのホスト名とポート番号で開けなければならない（SHALL）。インターネット側へは公開しない（MUST NOT）。

#### Scenario: 手元の PC から開く
- **WHEN** 同じ LAN の PC のブラウザで `http://<ラズパイのホスト名>.local:8501` を開く
- **THEN** かんたん LeRobot の画面が表示される

### Requirement: 操作できる人の制限
画面を開いた人は、設定されたパスワードを入力するまで、どのステップの画面も表示できず、コマンドの起動や入力の送信もできてはならない（MUST NOT）。パスワードはラズパイ上の設定ファイルに置き、git 管理には含めない（MUST）。

#### Scenario: パスワードを知らない人が開く
- **WHEN** パスワードを入力せずに、または誤ったパスワードで画面を開く
- **THEN** パスワードの入力欄だけが表示され、アームは動かせない

#### Scenario: パスワードが設定されていない
- **WHEN** パスワードの設定ファイルがないまま画面を起動する
- **THEN** 画面はどのステップも表示せず、パスワードの設定方法を案内する

### Requirement: 電源を入れると立ち上がる
ラズパイの電源を入れると、ログイン操作なしで画面が起動しなければならない（SHALL）。画面のプロセスが異常終了した場合は自動で再起動する（SHALL）。

#### Scenario: 電源を入れ直す
- **WHEN** ラズパイの電源を切って入れ直し、起動が終わるまで待つ
- **THEN** 手元の PC のブラウザから画面を開ける

#### Scenario: 画面のプロセスが落ちる
- **WHEN** 画面のプロセスが異常終了する
- **THEN** 画面は自動で再起動し、実行中だった録画や学習の結果は command-runner の run.json から反映される

### Requirement: 推論の実行場所
デモの推論は、ラズパイ上で行う方式（ローカル推論）と、GPU のある PC の推論サーバーで行う方式（リモート推論）を、ラズパイごとの設定で切り替えられなければならない（SHALL）。既定はローカル推論とする。どちらの方式でも、デモ画面の操作（開始・停止・成功と失敗の記録）は変わってはならない（MUST NOT）。

#### Scenario: ローカル推論でデモする
- **WHEN** 推論の実行場所がローカル推論に設定されている状態でデモを始める
- **THEN** ラズパイ上で学習済みモデルが読み込まれ、アームが動く

#### Scenario: リモート推論でデモする
- **WHEN** 推論の実行場所がリモート推論に設定され、推論サーバーの接続先が設定されている状態でデモを始める
- **THEN** ラズパイは推論サーバーへ観測を送り、受け取った動作でアームが動く

#### Scenario: 推論サーバーにつながらない
- **WHEN** リモート推論の設定でデモを始めたが、推論サーバーにつながらない
- **THEN** アームは動かず、画面は推論サーバーにつながらない旨と接続先を表示する

### Requirement: デモ中はインターネットに依存しない
ローカル推論では、デモを始める前に学習済みモデルをラズパイに取得しておき、デモの実行中はインターネット接続がなくても動作しなければならない（SHALL）。

#### Scenario: 会場のネットがない
- **WHEN** 学習済みモデルを取得済みのラズパイを、インターネットにつながらない LAN でデモに使う
- **THEN** ローカル推論でデモを実行できる

#### Scenario: モデルをまだ取得していない
- **WHEN** 学習済みモデルを取得していない状態で、インターネットにつながらないままデモを始める
- **THEN** デモは始まらず、画面はモデルの取得が必要である旨を表示する
