# Spec Delta

## Purpose

ノート PC を使わず、ラズパイ 4 とスマホだけでミラー（リーダーの動きをフォロワーに映す）を行えるようにする。そのための実機の配線、スマホからの操作、Linux でのアームのプロセス管理を定める。

## ADDED Requirements

### Requirement: 実機の配線
ラズパイ 4 には、リーダーのサーボ基板とフォロワーのサーボ基板を USB で 1 本ずつ、ラズパイの電源、USB ハブ経由のカメラ 2 台をつながなければならない（SHALL）。カメラはフォロワーに付ける 1 台（`wrist`）と、アームとつかむ物体の距離を見る定点カメラ 1 台（`front`）とし、リーダーにはカメラを付けない（MUST NOT）。サーボの電源は各アームの電源から取り、ラズパイの USB から取ってはならない（MUST NOT）。ラズパイには画面とキーボードをつながない。

#### Scenario: 配線を確かめる
- **WHEN** ラズパイにリーダー・フォロワー・USB ハブ（カメラ 2 台）・電源をつないで起動する
- **THEN** `/dev/serial/by-id/` にサーボ基板が 2 つ、`/dev/v4l/by-id/` にカメラが 2 台見える

### Requirement: スマホからの操作
画面はラズパイ上で動くサーバーが提供し、ラズパイと通信できるネットワークにいるスマホのブラウザから開いて操作できなければならない（SHALL）。スマホとラズパイのつなぎ方（端末同士の通信ができない学校の open Wi-Fi の代わり）は本提案では定めない。画面の表示と操作はスマホの縦長の画面で行えなければならない（SHALL）。

#### Scenario: スマホで開く
- **WHEN** ラズパイと同じ Wi-Fi のスマホのブラウザで `http://<ラズパイの IP アドレス>:8501` を開き、パスワードを入れる
- **THEN** モード選択の画面が表示され、mirrorMODE に進める

### Requirement: ポートの指定
リーダーとフォロワーのポートは、コードを書き換えずにラズパイごとの設定で指定できなければならない（SHALL）。設定がないときは OS ごとの既定値（Windows は `COM19`・`COM20`、Linux は `/dev/ttyACM0`・`/dev/ttyACM1`）を使う（SHALL）。ポートが見えているかの判定では、シンボリックリンクで指定したポートも見えているものとして扱う（SHALL）。

#### Scenario: by-id の名前で指定する
- **WHEN** 設定でリーダーのポートに `/dev/serial/by-id/` の名前を指定し、そのリンク先の `/dev/ttyACM0` が存在する
- **THEN** mirrorMODE のリーダーの表示は「接続」になる

#### Scenario: 設定がない Windows の開発機
- **WHEN** 設定なしで Windows の開発機で画面を開く
- **THEN** これまでどおり `COM19`・`COM20` を使う

### Requirement: Linux でのアームのプロセス管理
Linux では、ミラーと録画のプロセスを Windows と同じ約束で扱わなければならない（SHALL）。停止は Ctrl+C と同じ割り込みで後片付け（ポートを閉じる、データセットを確定する）を走らせ、決めた時間を過ぎても動いていればそのプロセスの子まで止める（SHALL）。画面を開き直しても、サーバーを再起動しても、動いているプロセスを見失ってはならない（MUST NOT）。

#### Scenario: ミラーを止める
- **WHEN** ラズパイでミラーを動かしている間に「停止」を押す
- **THEN** mirror_leader は後片付けをして終わり、画面は停止中の表示に戻る。止めた結果を失敗とは表示しない

#### Scenario: 止まらないプロセス
- **WHEN** 割り込みを無視するプロセスに停止を求め、待ち時間を過ぎる
- **THEN** そのプロセスと子プロセスはすべて終わり、取り残しは 0 件になる

### Requirement: キー送信が使えない環境
画面のない Linux のように、OS へのキー送信が使えない環境でも、画面全体は起動しなければならない（SHALL）。キー送信が要る操作（録画の「この回を終える」「撮り直す」）だけを無効にし、理由を表示する（SHALL）。

#### Scenario: ラズパイで録画画面を開く
- **WHEN** 画面のないラズパイで録画画面を開く
- **THEN** 画面はエラーにならず、「この回を終える」「撮り直す」は押せず、キー送信が使えない旨が表示される
